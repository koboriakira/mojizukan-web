## 技術制約

- Cloudflare Workers + Hono + D1（SQLite）
- クライアント JS は TypeScript 文字列テンプレートとして埋め込み（フレームワークなし）
- 画像は R2 に保存、URL は `/r2/` プレフィックスで配信
- Workers AI を使用（API キー不要）
- 画像生成は `gpt-image-1-mini`、サイズは 1024x1024 のみ対応（512x512 不可）

## 前回のデザインからの変更・発見

- **はっけん画面タイトル色の変更**: 「ずかんに のったよ！」をオレンジ → 説明文と同色（#5a5145）に。手書きフレームを視覚的に主役にするため
- **旧おはなしフロー（同期SSE）を完全削除**: 非同期フロー（POST→202→ポーリング）に一本化
- **登録ゲート・ログインシートは既存の signup シートで対応済み**: authReason による文言分岐、認証後の自動遷移を実装。Issue #140, #112 はクローズ
- **gpt-image-1-mini は 512x512 未対応**: 1024x1024 / 1024x1536 / 1536x1024 のみ。画像サイズ最適化は API 制約で不可

## 今回お願いしたいこと

### 1. 実装完了のレビュー

前回 decisions のフロー・画面状態と、現在の実装が一致しているか全体チェック。漏れ・不整合・改善すべき点があれば指摘してほしい。

特に確認してほしい点:
- ゲストフローの体験（みつける→なぞり→はっけん→ずかん→登録促し）
- 認証後の遷移先（story/tanken/null による分岐）
- チケット残高0のフロー（たんけんで新規語→キャッシュミス→「なくなったよ」）
- 手書き文字表示の見せ方（フレームの存在感・サイズ感）

### 2. オリジナルスタイル（#109）のデザイン

保護者が独自のプロンプトを設定し、プリセット5種（ほんわか/えほん/ポップ/水彩/ずかん）以外のスタイルで画像を生成できる機能。

#### 背景
- プリセットスタイルは共有キャッシュで効率化されるが、「自分だけの絵」を求める保護者にカスタマイズの余地を残したい
- オリジナルスタイルは毎回 API 呼び出し（キャッシュ不可）→ チケット消費の対象

#### 検討してほしい問い
- オリジナルスタイルの設定画面はどこに置くか（保護者メニュー内？しょうさい画面？）
- プロンプト入力の UI（自由テキスト？テンプレート選択＋カスタマイズ？）
- プリセット ↔ オリジナルの切り替え UX
- 子ども画面でのオリジナルスタイルの見え方（バッジ？特別な枠？）
- オリジナルスタイルでの再発見（再生成）はチケットを消費するか
