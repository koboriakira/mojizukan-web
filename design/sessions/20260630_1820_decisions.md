# Handoff: もじずかん (Mojizukan) — 幼児向け 手書き文字あつめ & はっけん & おはなし生成

> このREADMEは**現行プロトタイプ `Mojizukan-Hakken-Prototype.dc.html` の確定仕様**を単独で実装できるよう自己完結でまとめたものです。
> 旧 `Mojizukan-Prototype.dc.html` 用の記述（および `HAKKEN-HANDOFF.md` / `MITSUKERU-HANDOFF.md` / `TANKEN-HANDOFF.md`）はこの版に統合・更新されています。差異がある場合は**本READMEと `Mojizukan-Hakken-Prototype.dc.html` を正**としてください。

## Overview
もじずかん は、子どもが画面に文字を「なぞって書く」ことでひらがなの言葉を集め、図鑑（ずかん）として育てる幼児向けWebアプリです（対象 約3〜6歳・モバイル縦画面）。

子どもの2つの遊び方 + 保護者の準備:
1. **みつける（おまかせ発見）** — 用意された言葉を1つ出題。子どもは*何の言葉かを伏せられたまま*なぞり、書き終えると正体（絵・名前・説明）が判明。
2. **たんけん（じぶんで作る）** — 50音キーボードで子ども自身が言葉を作り、なぞって発見。1日の回数を保護者が設定。
3. **ずかん** — 集めた言葉をカテゴリ別コレクションとして閲覧。未発見は「？」。
4. **おはなし（サインイン後・チケット消費）** — 集めた言葉から短い絵本を生成。**会員登録（サインイン）必須**で、1冊につき🎟️1枚消費。トップは絵本だな（ライブラリ）で「作るモード」＋「これまでに作ったお話一覧」。生成は約1分かかるため**バックグラウンド処理**とし、執筆中も一覧に並べ、待ち時間は他の遊び（みつける/たんけん）へ誘導。完成した絵本はいつでも読み返せる。本文中のモノ名は子どもが書いた手書き文字画像に差し替え。
5. **おうちの方メニュー（保護者ゲートの先）** — 今日の準備（みつける用の言葉仕込み・たんけん回数）、学習記録、チケット購入(Stripe)、設定。

> **サインインの位置づけ（重要）**: チケットは会員のみが保有でき、**たんけん と おはなし はチケットを使う＝サインイン後の機能**。ゲストがホームで両機能を押すと、登録/ログインを促すシート（機能別の案内コピー）を表示し、認証完了後に目的の機能へ自動遷移する。みつける と ずかん はゲストでも利用可。

## About the Design Files
このバンドルの **`Mojizukan-Hakken-Prototype.dc.html` が唯一の最新デザインリファレンス**（全画面・全ロジックを含む）です。HTMLで作られた**プロトタイプ**であり、そのまま本番に貼るコードではありません。

## Layout / 全体
- モバイル縦画面前提。中央寄せ、`max-width: 560px`、左右 `padding: 0 20px`、下 `padding-bottom: 28px`。
- 本文フォント **Zen Kaku Gothic New**、見出しフォント **Zen Maru Gothic**（いずれも Google Fonts、500/700/900）。
- 単一コンポーネント内の `screen` ステートで画面を切替（SPA）。モーダルは下からスライドインするボトムシート（`sheet` ステート）。
- 全タップ要素に `.tap` クラス相当の押下感: `:active` で `translateY(3px) scale(.98)`、transition .08s。

### 子ども画面 と 保護者画面 のトーン使い分け（重要）
- **子ども画面**（ホーム/みつける/たんけん/てがき/のったよ/ずかん/しょうさい/おはなし）: **ひらがな主体**・分かち書き・絵文字・まる文字見出し。
- **保護者画面**（おうちの方メニュー/はっけん準備/各確認シート）: **通常の日本語表記（漢字・通常の文章）**。専門用語は平易に。
- 「みつける」「たんけん」は機能名として保護者画面でもそのまま使用。

### 2. Write（てがき / なぞり書き）— 中核体験
お手本をなぞって1文字ずつ書く。**新しいなぞりフィードバック**を搭載（詳細は後述「なぞりフィードバック実装メモ」）。
- **ヘッダ**: 戻る(円56px白) / 中央ラベル / 右に **🔊 ボタン**（円56px白、押すと*今なぞる1文字*を音声読み上げ）。
  - 中央ラベルは出題モードで変化:
    - **みつける（発見モード, `revealKind==='mitsuke'`）**: 「**なぞって みよう！なにが でるかな？**」← *正体を伏せる*（ネタバレ防止。重要仕様）。
    - それ以外（たんけん/通常/復習: 子どもが既に語を知っている）: 「**「◯◯」を なぞろう**」。
- **進捗ボックス**: 文字数分の `64px` 角丸16pxマス（`--card`/border `--cbd` 3px）。確定済み文字を 38px 表示。
- **キャンバスカード**: `max-width:380px`, `aspect-ratio:1`, bg白, 角丸24px, 影 `0 4px 16px rgba(0,0,0,.07)`, `overflow:hidden`, `touch-action:none`。中に `<canvas>` 1枚（お手本・インク・キラキラを全てCanvasで描画。DOMのお手本文字は廃止）。
- **下段操作**: 「↩ もどす」「けす」（各 flex:1, 60px, 角丸18px, 白）。
- **はげまし文**（キャンバス下, 14.5px/700, `min-height:20px`）: 未描画「ゆびで なぞってね ✏️」(`#b6ab9a`) → 描画後「いいね！かけたら ボタンを おしてね」(`#3f8e63`)。
- **確定ボタン**（`min-height:80px`, 角丸22px, 26px/900, transition .2s）:
  - **未描画**: 淡色 `bg #d8cfc0 / 影 #bfb6a6`、ラベル「**かいて みよう**」、押しても進めない（ゲート）。
  - **描画あり**: bg `--accent2` / 影 `--accent2d`、ラベル「**なぞれたよ！**」（最後の1文字では「**できた！**」）。
- **進行**: 文字確定で進捗ボックスが埋まりキャンバスをリセット、次の文字へ。最後の文字確定で:
  - 通常/たんけん辞書語 → **Reveal**。
  - 発見モード（みつける secret / たんけんで新語） → **HakkenGen（生成演出）** を経て Reveal。

### 3. Reveal（のったよ / 図鑑登録演出）

- 画面表示時に語を**自動読み上げ**（読み上げONかつ対応ブラウザ時）。
- 復習（すでに図鑑にある語を再度書いた）時は、追加の保護者向けバナー（「この ことばは もう ずかんに いるよ！」＋ おうちの方へのヒント）を表示。
- アクション: 「つぎも かく！」（発見/復習系は「みつける」へ戻る、通常は新しい語へ）/「ずかんを みる」。

### 4. Mitsukeru — 全部発見済み画面（`screen==='mitsukeru'`）
みつけるの出題プールが尽きたとき表示。上部にやさしいグラデバナー「いまの ことばは ぜんぶ みつけたよ！」＋「パパや ママに そうだんしてね」。中央 `📖`(bob)。下に「🏠 おうちの ひとに みせる」（保護者ゲートへ）。

### 5. Tanken（たんけん / 50音で言葉を作る）
- **ヘッダ**: 戻る / 中央「🧭 たんけん」(`--accent`) / 右に「きょうの はっけん」ピップ列（`dailyHakkenMax` 個のドット、使用済みは `--accent3` 塗り）。
- サブ「すきな ことばを つくって なぞろう」。
- **入力スロット行**: 作成中の文字を 44px角丸12pxチップで表示（最大6文字）+ 末尾に空きスロット。右に「ぜんぶ けす」(52px)。
- **変換バー**: 「⌫ もどす」/「゛」(濁点)/「゜」(半濁点)/「小」(小書き)/「ー」(長音)。直前の文字を変換（マップ `DAKU`/`HANDAKU`/`SMALL`）。
- **50音グリッド**: `ROWS`（あ行〜わ行、空マスは透明プレースホルダ）。各キー `aspect-ratio:1`, 白, border `--cbd`, 23px/900。**タップで1文字追加＋その文字を音声読み上げ**。
- **エラーメッセージ箱**（条件表示, `#fff0e6`/border `#f0c4ad`）: 重複「📖 「◯◯」は もう ずかんに あるよ！」/ 不正「🙈 この ことばは まだ つくれないみたい。」。
- **CTA**「✏️ これを かく（N もじ）」: 1文字以上で `--accent` 有効、0文字は淡色。
- **判定 `classifyTanken(w)`**: NGワード→`ng` / 既取得→`dup` / 辞書(非はっけん)→`dict`（無料で書ける）/ それ以外→`hakken`（新語）。
  - `hakken` かつ「本日の回数超過（`dailyHakkenUsed>=dailyHakkenMax`）またはチケット0」→ **TankenLimit** 画面へ。

### 6. TankenLimit（たんけんおしまい）
`🌙`(bob) +「きょうの たんけんは おしまい！」+「『◯◯』は あした はっけん できるよ。いまは みつける で あそぼう！」+「※ かいすうは おうちの方が きめています」。アクション「🔍 みつける へ」/「🏠 ホーム」。

### 7. HakkenGen（はっけん中 / 生成演出）— **全体キャッシュ連動・2段階**
新語を図鑑化する間の演出。**「全体キャッシュ（`スタイル｜単語`）にヒットするか＝既生成データの即返却か、生成AIでの完全新規作成か」で演出と待ち時間を切り替える**（体験が単調にならないようミス時のみ段階推移）。共通要素は `✨⭐✨`、3点パルス（`dotpulse`/`--accent3`）、「🎨 ◯◯ スタイル」チップ。
- **キャッシュヒット（`genCached=true`）= 高速・1段階**: 円カード絵文字 `📖`（緑系ラジアルグラデ `#e3f7e8→#fff3d6`／`pop` アニメ）+「ことばを よびだして いるよ」+ フッタ「ずかんから すぐに もってくるよ…」。プロトタイプ **~1.2s** で Reveal。
- **キャッシュミス（`genCached=false`）= 低速・2段階**（プロトタイプ合計 **~6.6s**）:
  - **1段目（`genPhase===1`, 0〜~2.7s）**: 絵文字 `🔍`（ピンク系グラデ／`bob 1.1s`）+「ことばを さがして いるよ」。
  - **2段目（`genPhase===2`, ~2.7s〜）**: 絵文字 `🔎`（紫系グラデ `#e6e1ff→#ffe6f2`／影濃いめ／`bob .8s` で“がんばってる”感）+「うーん、むずかしい ことば！もっと しらべて いるよ」+ バッジ「🌟 はじめての ことばを つくっているよ」(`rise` で出現)。
  - 両段ともフッタ「AIが えと せつめいを かいているよ…」。
- **状態/タイミング**: `confirmChar()` の発見完了で `screen:'hakkengen'` にしたあと `startHakkenGen()` を呼ぶ。`isCached(word)` でヒット判定 → ヒット時は単一タイマー(1.2s)、ミス時は 2.7s で `genPhase=2` に推移 + 6.6s で `finishHakken()`。`finishHakken()` は完了時に **`_imgCache.add(スタイル｜単語)`** で結果をキャッシュへ保存（同一スタイルで再生成すると次回はヒット＝高速になる）。
- **本番接続**: プロトタイプのタイマーは、本番では「キャッシュ照会の往復（速い）」と「生成API待ち（遅い）」の実レスポンスに置き換える。ミス時の段階推移は経過時間ベースでよい（例: 一定秒数を超えたら2段目メッセージへ）。詳細は「画像生成スタイル > 全体キャッシュ連動」節。

### 8. Zukan（ずかん / 図鑑）

- **ゲスト時**: 点線枠の登録促しCTA（border `--accent` dashed、「いまは ゲスト ・ とうろくで ずっと のこそう」）。
- **ひみつの ことば セクション**（`seeded` がある時）: 見出し「⭐ ひみつの ことば N こ」+「? を かいて はっけんしよう！」。点線(`#e3b8cd`)カードに大きな `?`(#c2698f) +「かいて みよう」。タップで該当語の Write（発見モード）へ。
- **seeded が無い時**: 「✨ あたらしい ことばを ふやそう / おうちの方が『ひみつの ことば』を 仕込めます」CTA（保護者ゲートへ）。
- **カテゴリ別**（`CATS`）: アイコン+名前(20px/900)+進捗`got/total`、下に `grid (repeat(auto-fill,minmax(96px,1fr)), gap12px)`。

  - 未取得セル: bg `--locked`/角丸20px/中央 `?`(#c4b6a0)。
- **⭐ はっけん セクション**（`discovered` がある時）: セル border `#f3dd9a`。

### 10. おはなし（Story Home / Pick / Read）— サインイン後・チケット消費
**入口 `goStoryHome` はゲストを登録シートへ送る**（`authReason:'story'`）。同様に `goTanken` も `authReason:'tanken'` で送る。認証後は目的画面へ自動遷移（`_afterAuth`）。

#### 10-a. Story Home（おはなし・ほんだな / ライブラリ）`screen==='storyhome'`
お話機能のトップ。**作るモード＋作成済み一覧＋執筆中一覧**を1画面に集約。
- **ヘッダ**: 戻る(→ホーム) / 「📚 おはなし」(`--accent3`) / 右に `🎟️ N`。
- **作成CTA**（大ボタン, `min-height:86px`, bg `--accent3`, 影 `--accent3d`）: ✏️ +「あたらしい おはなしを つくる」23px/900 + 補足「ことばを えらんで AIが えほんに ・ 🎟️1まい」。タップで Story Pick。
- **執筆中バナー**（`anyWriting` のとき, グラデ `#fbeaf1→#fff3d6`, border `#e3b8cd`）: ✏️(bob) +「おはなしを かいているよ（1ぷんくらい）」+「まっている あいだに、あたらしい ことばを みつけに いこう！」+ 並列ボタン「🔍 みつける」(`--accent2`)「🧭 たんけん」(`--accent`)。**待ち時間の回遊導線**（要件）。
- **見出し**「つくった おはなし」(16px/900/`--sub`)。
- **一覧**（`storyHomeList`、新しい順）: 横長カード（白/border `--cbd` 2px/角丸20px/影 `0 3px 0`）。左に64px角丸16pxのカバー（ページ別パステル `tint` 地に語の絵文字を2つまで）。右に語（`◯・◯`, 17px/900, 1行省略）。
  - **完成 `isDone`**: サブ「YYYY/M/D に できた ・ よむ ›」+ 右端 `›`。タップで Story Read。
  - **執筆中 `isWriting`**: 「かいているよ…」(`--accent3`/900) + 3点パルス。**タップ不可**（`onOpen` は no-op）。
- **空状態 `noStories`**: 点線枠プレースホルダ「まだ おはなしが ないよ。/ 『つくる』を おして、はじめての えほんを つくろう！」。
- プロトタイプは初期に完成済みサンプル1冊（`ねこ・りんご`）をシードして一覧を再現。

## なぞりフィードバック 実装メモ（最重要・新規）
「塗りつぶし達成率」ではなく、**なぞる行為そのものを気持ちよくする**方針。塗り率ゲートは廃止。

### Canvas 構成（Write画面）
表示用 `<canvas>` 1枚 + **オフスクリーン2枚**（インク用 `ink`、お手本マスク用 `mask`）を同サイズで保持。粒子配列 `parts[]`。
1. **お手本マスク `mask`**: 対象1文字を `Zen Maru Gothic 900`、`fontSize ≈ canvasH*0.66`、中央に黒で塗り描画（`buildMask`）。文字が変わるたび再生成。フォント未ロード時のズレ防止に `document.fonts.ready` 後へ再ビルドフック。
2. **インク `ink`**: ポインタ操作で線を描く。`lineWidth ≈ max(15, H*0.08)`, `round`, `strokeStyle = --accent`（テーマ追従）。**描画はこのオフスクリーンに蓄積**（表示Canvasには都度合成）。
3. **表示合成 `renderTrace()`**（毎フレーム）: クリア → お手本 `mask` を `globalAlpha 0.14` で薄く描画（=なぞる対象のガイド）→ `ink` を等倍描画 → 粒子を描画。
4. **キラキラ粒子 `spark(x,y,n)`**: ポインタ down / 一定距離ごとの move で数個生成。色は `['#ffd24a','#ff9e5e','#7ad0a0','#f0a6c4','#ffffff']` からランダム。各粒子 `{vx,vy,life,decay,size,rot,col}`、重力 `vy+=0.05`、`vx*=0.98`、`life-=decay` で消滅。4点星形（`starPath`）で描画、`globalAlpha=life`。上限200個。
5. **アニメループ `startLoop()`**: `requestAnimationFrame` で `renderTrace` を回し、**描画中 or 粒子が残る間だけ**継続（idleで停止しCPU節約）。Canvas が消えたら停止。
6. **チャイム音 `twinkle()`**: Web Audio。`AudioContext` を初回ポインタで遅延生成（gesture後）。ペンタトニック `[523.25,587.33,659.25,783.99,880,1046.5]` からランダムな1音を `sine` で短く（gain 0→0.1→0、~0.22s エンベロープ）。最短85ms間隔にスロットル。**効果音設定 `sfx` OFF で無音**。
7. **完了ゲート**: 「描いたか」だけ。最初のストロークで `drew=true`。確定ボタンは `drew` で有効化。`confirmChar()` 冒頭で `if(!drew) return`。`けす`/`もどす`で `drew=false`・粒子クリア・`ink` クリア。
8. **手書きキャプチャ**: `ink.toDataURL('image/png')`（=子どもの実際のストロークのみ、お手本/粒子は含めない）。

### 音声読み上げ（任意・読めない子向け）

## 画像生成スタイル（保護者が選択・新規）
保護者が**生成イラストの画風（タッチ）を5択から選び、みつける と たんけん の両方の生成画像に適用**する機能。プロトタイプでは絵文字をイラストのプレースホルダとし、**画像を囲む枠装飾＋絵文字へのCSSフィルタ**で各画風を表現する。本番はこの `imgStyle` 値を生成API（画像生成プロンプト）に渡し、実際の挿絵タッチを切り替える。

|---|---|---|---|
| `honwaka` | ほんわか | パステルで まるく やさしい タッチ | パステル多色グラデ地・枠なし・大角丸42px・やわらか影・`saturate(.9)` |

### 適用箇所（みつける・たんけん 共通）
画像を出すすべての画面で、選択中スタイルの枠装飾を適用し、**🎨 スタイル名チップ**を併記する:
1. **Reveal（のったよ）**: 200px 絵文字カードに `frameBg/frameBorder/frameShadow/frameRadius/frameRotate` を適用、絵文字 `<span>` に `frameFilter`。カテゴリチップの隣に「🎨 ◯◯」チップ（白地/border `--cbd`）。
2. **Detail（しょうさい）**: 220px カードに同じ枠＋フィルタ。カテゴリチップ隣に「🎨 ◯◯」チップ。
3. **HakkenGen（はっけん中・生成演出）**: ローディング中に「🎨 ◯◯ スタイル」チップを表示し、どの画風で生成中かを明示。
> reveal/detail は同一の `frame*` 値（＝現在の `imgStyle`）を共有。両画面は同時表示されないため単一セットで足りる。

### 状態 / メソッド
- 状態 `imgStyle`（既定 `'ehon'`）。
- `openStyleSheet()` → `sheet:'style'`。`pickStyle(key)` → `imgStyle` を更新（シートは閉じない＝比較しながら選べる）。
- `renderVals()`: `sf = STYLE_DEFS[imgStyle]` から `frameBg/frameBorder/frameShadow/frameRadius/frameFilter/frameRotate` と `styleName` を、`STYLE_ORDER.map(...)` から `styleOptions`（`sw*` プレビュー値・選択フラグ・`onPick`）を算出。
- スタイル変更は**既存の生成済み画像に遡及しない**（次回以降の生成に適用）。プロトタイプは絵文字を使うため見た目上は枠が変わるが、本番は「生成済み挿絵は保存値のまま」を原則とする。

### カスタムスタイル（保護者が自作・新規）
プリセット5種に加え、保護者が**プロンプトを記述して独自の画風を1つ作成**できる（`imgStyle:'custom'`）。
- **状態**: `customStyle`（`null` または `{name, prompt}`）/ 編集中ドラフト `csName`・`csPrompt` / 生成セッション期限 `editSessionEnd`(ms) / `csGenerating` / `csSamples[]`。`customFrame()` がカスタム用の枠定義（紫系グラデ地・点線枠 `#c2a8e0`・角丸30px 等＋シート用 `csSw*`）を返す。
- **編集セッション（要件の核心）**: プロンプトの**編集はいつでも可能**。ただし**サンプル試し生成は「チケット1枚消費で開始する15分間のセッション」内でのみ可能**。
  - `startCsSession()`: チケット0なら Tickets シート、それ以外は Custom Start 確認シート → `confirmCsStart()` で `tickets-1`・`editSessionEnd=Date.now()+15*60*1000`。
  - `csRemainMs`（=`max(0, editSessionEnd-now)`）/ `csActive`（>0）で残時間・可否を判定。`csGenerate()` は `csActive` のときのみ実行（期限切れは no-op）。
  - 期限切れ後は編集UIは生きたまま、生成ボタンが「チケットを使って15分間サンプルを試す」に変わる。
  - カウントダウン表示は `componentDidMount` の 1秒 interval（`customstyle` 画面のときのみ `forceUpdate`）。
- **保存**: `saveCustomStyle()` で `customStyle` を確定し `imgStyle:'custom'` に。以後 reveal/detail/hakkengen の枠は `customFrame()`、本番は `customStyle.prompt` を画像生成APIへ渡す。
- 詳細UIは「Screens > 13. カスタムスタイル作成」「Bottom Sheets > Custom Start」を参照。

### 全体キャッシュ連動（新規）
同一スタイル×同一単語は**全体（=全ユーザー共有）キャッシュ**として保存済みの画像・説明文を即返却する設計。これにより、みつける／たんけん の生成は「キャッシュ済み（速い）」と「完全新規＝生成AI必須（遅い）」に二分され、待ち時間が体感で大きく変わる。HakkenGen の演出はこれに連動させ、退屈にならないよう**ミス時のみ2段階に推移**させる（「Screens > 7. HakkenGen」参照）。
- **キー**: `cacheKey(word, style) = style+'|'+word`。`isCached()` でヒット判定。`finishHakken()` 完了時に `_imgCache.add(...)` で結果を保存。
- **プロトタイプの模擬**: `_imgCache` は `Set`。デモ用に頻出語（いぬ/ねこ/りんご/ばなな/て/め/うさぎ/つき/にじ/ほし）× 全プリセットスタイルを事前ヒットとしてシード。**カスタムスタイルや珍しい語は未キャッシュ＝常にミス（2段階演出）**。スタイルを切り替えると同一語でも未キャッシュ扱いになり再生成挙動を再現できる。
- **本番接続**: タイマーを「キャッシュ照会の往復」と「生成API待ち」の実レスポンスに置換。ヒット時は単一の短いローディング、ミス時は経過時間で2段目メッセージへ。生成成功後にサーバ側キャッシュへ登録。

## 仕様決定の追補（未確定だった4点）
レビューで保留だった論点の確定事項。上記本文に反映済みのものも含め、ここに方針を集約する。

### A. おはなしの品質基準（本番AI生成の受け入れ基準）
文数・ひらがな制約に加え、物語としての質を**生成プロンプト規約＋自動チェック＋人手rubric**の3層で担保する。
- **構成**: 3〜5文を「① 場面 → ② 出会い／できごと → ③ おしまい」の極小アーク。起承転結は強制しない（3〜6歳は単線の因果で十分）。落ち（「おしまい」）必須。
- **キャラ一貫性 / カテゴリ整合**: 選択語＝登場人物として全文で役割を保持。語の属性に反する動作を禁止（例: たべものは「あるかない／わらわない」）。
- **可読性**: 1文 ≤ 18〜20文字、全ひらがな＋分かち書き、既習語中心、難語・抽象語禁止。
- **情緒安全性**: こわい・かなしい・暴力・別れ等を回避（NGワードとは別レイヤーの情緒ガード）。
- **リズム**: 繰り返し・擬音・心地よい語尾を加点。
- **語の網羅**: 選択語を**全部**最低1回登場（取りこぼし禁止）。
- **自動チェック**: 文長 / ひらがな率 / 語網羅 / NG を機械判定し、不合格は再生成。
> プロトタイプの `buildStory()` はテンプレ連結の模擬。本番は上記rubricでプロンプト設計＆検証する。

### B. ログアウト後の遷移 / データ保持（**MVPでは実装しない**）
方針のみ確定。MVP対象外（`authed` を落とす導線を出さない）。本実装フェーズで採用:
- **置き場所**: 設定カード内＝保護者ゲートの先（子どもの誤操作防止）。
- **遷移先**: 実行後 **ホーム＋ゲスト状態**へ。「ログアウトしました」を控えめに表示。
- **データ**: ローカルの図鑑は端末に保持（再ログインで同期）。完全削除は別アクション「このデバイスのデータを消す」に分離。

### C. 自発的サインイン導線（実装済み）
復帰ユーザー向けの入口を追加。**Home のログインリンク**（`isGuest` 時）と **Signup シートのリンク**の2経路 → **Login シート**。詳細は「Home」「Bottom Sheets > Login」参照。

### D. バックグラウンド音声との共存（共存＝許容、明文化のみ）
- なぞりチャイム（Web Audio）・読み上げ（speechSynthesis）は**非排他ミックス**。ユーザーが再生中の他アプリ音楽を停止せず、メディアセッションも奪わない。

### H. 全体キャッシュ連動の生成ローディング（今回更新・確定）
同一スタイル×同一単語は全体キャッシュから既生成データを即返却し、それ以外は生成AIで新規作成する。この速度差を HakkenGen の演出に連動させる。
1. **キャッシュヒット＝高速・1段階**（`genCached`）: 「よびだしている」系の短いローディング。
2. **キャッシュミス＝低速・2段階**（`genPhase` 1→2）: 1枚目「さがしている」→ 一定時間後 2枚目「むずかしいことばだ、もっとしらべている」＋バッジで変化をつける（退屈防止）。
3. **キーと保存**: `cacheKey=スタイル｜単語`。生成成功時にキャッシュ登録し、同スタイルで再生成すると次回はヒット（高速）。スタイル変更は同一語でも未キャッシュ扱い＝再生成。
> 本番はタイマーを「キャッシュ照会の往復」と「生成API待ち」の実レスポンスに置換。詳細は「Screens > 7. HakkenGen」「画像生成スタイル > 全体キャッシュ連動」節を参照。
