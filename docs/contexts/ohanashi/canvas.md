# Bounded Context Canvas: おはなし

| 項目 | 内容 |
|------|------|
| **分類** | コアドメイン（独立） |
| **目的** | ずかんに集めたことばを素材に、AIが絵本を生成して読む体験を提供する |
| **戦略的重要性** | 高。ことばあつめとは独立したサービスだが、ずかんの語を使う点で価値が連動する |

## ユビキタス言語（主要）

おはなし、ページ、語選択、手書き差し替え

→ 詳細は [glossary.md](../../glossary.md)

## メッセージ

### 受信（Inbound）

| メッセージ | 送信元 | 内容 |
|-----------|--------|------|
| 語一覧 | ことばあつめ | ずかん登録済みのことば（素材候補） |
| canSpend 結果 | アカウント・経済 | チケット残高の確認 |
| 生成結果 | AI生成 | 絵本テキスト（SSE ストリーミング） |

### 送信（Outbound）

| メッセージ | 送信先 | 内容 |
|-----------|--------|------|
| 生成リクエスト | AI生成 | 選択された語 → 絵本テキスト生成 |
| spendTicket | アカウント・経済 | おはなし生成時にチケット消費 |

## 主要ルート

| エンドポイント | 役割 |
|---------------|------|
| `POST /api/story/stream` | おはなし生成（SSE ストリーミング） |
| `GET /api/stories` | 保存済みおはなし一覧 |
| `GET /api/stories/:id` | おはなし詳細 |

## ことばあつめとの関係

- おはなしは ことばあつめの語一覧を**参照するだけ**の一方通行（Published Language）
- ことばあつめ側にはおはなしの存在を知る必要がない
- 将来的におはなし単体でも成立しうる独立したサービス

## 変更時の注意

- おはなし内部の変更はことばあつめに影響しない（独立性を維持）
- チケット消費枚数の決定は人間判断
- SSE ストリーミングのイベント形式を変える場合はクライアント側も確認
