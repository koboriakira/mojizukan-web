# Handoff: もじずかん (Mojizukan) — 幼児向け 手書き文字あつめ & おはなし生成

## Overview
もじずかん は、子どもが画面に文字を「なぞって書く」ことでひらがなの言葉を集め、図鑑（ずかん）として育てていく幼児向けWebアプリです。本ハンドオフは MVP の確定デザイン・要件をまとめたものです。

主な体験:
1. **もじをかく** — お手本をなぞって1文字ずつ書き、言葉を完成させる
2. **ずかん** — 集めた言葉をカテゴリ別コレクションとして閲覧
3. **はっけん** — 辞書に無い言葉を AI で図鑑化（有料チケット消費・登録ユーザーのみ）
4. **おはなし**（本MVPで追加） — 集めた言葉から AI が3ページの絵本を生成。本文中のモノの名前を、子どもが実際に書いた手書き文字画像に差し替えて表示
5. **おうちの方メニュー** — 学習記録、チケット購入(Stripe)、設定（保護者ゲートの先）

## About the Design Files
このバンドルの `Mojizukan-Prototype.dc.html` は **HTML で作成したデザインリファレンス（プロトタイプ）** です。見た目と挙動の意図を示すもので、そのまま本番に貼り付けるコードではありません。

タスクは、これらのデザインを **ターゲットの開発環境（React / Vue / SwiftUI / ネイティブ等）の既存パターン・ライブラリで再現する** ことです。まだ環境が無い場合は、プロジェクトに最適なフレームワークを選んで実装してください（このアプリはモバイル縦画面前提・タッチ操作中心なので、React + Canvas、あるいはネイティブが有力）。

`.dc.html` / `support.js` は社内プロトタイピング用ランタイムのファイルです。**実装の参照用** であり、ランタイム自体を移植する必要はありません。ロジック（状態遷移・ストーリー生成・手書きキャプチャ）は HTML 内 `<script>` の `class Component` を読めば把握できます。

## Fidelity
**High-fidelity (hifi)**。色・タイポグラフィ・余白・角丸・影・アニメーションは確定値です。下記トークンに従ってピクセル単位で再現してください。挙動（なぞり書き、手書きキャプチャ、ページめくり）も確定仕様です。

データソースのみ未接続（プロトタイプはローカルのプリセット辞書・タイマーで AI を模擬）。本番では下記「Backend / 要件」を実装してください。

## Layout / 全体
- モバイル縦画面前提。コンテンツは中央寄せ、`max-width: 560px`、左右 `padding: 0 20px`、下 `padding-bottom: 28px`。
- ルート背景 `--bg`。本文フォント Zen Kaku Gothic New、見出しフォント Zen Maru Gothic。
- 画面遷移は単一コンポーネント内の `screen` ステートで切り替え（SPA）。モーダルは下からスライドインするボトムシート。

## Screens / Views

### 1. Home（ホーム）
- **Purpose**: 入口。3つの導線。
- **Layout**: 縦中央寄せ。絵文字ロゴ `📖✏️`(80px) → タイトル「もじずかん」(Zen Maru Gothic 900, `clamp(48px,15vw,72px)`) → サブ「もじを かいて あつめよう」(18px, `--sub`, 700) → ボタン群(`max-width:380px`, `gap:18px`)。
- **Components**:
  - 「✏️ もじを かく」: `min-height:84px`, `border-radius:24px`, bg `--accent` #e8714c, 文字白 24px/900, 下影 `0 5px 0 --accentd(#c95835)`。
  - 「📖 ずかんを みる」: 同形, bg `--accent2` #5fb583, 影 `--accent2d` #3f8e63。
  - **「📚 おはなしを つくる」**: 同形, bg `--accent3` #c2698f, 影 `--accent3d` #9c4d70。**図鑑3件以上（`collected.length >= 3`）でのみ表示**。右上に「NEW」バッジ（白地・#c2698f文字・6deg回転）。
  - 「🏠 おうちの ひとは こちら」: 透明ボタン, `--sub`, 18px/700。
- **Press feedback**: 全ボタン `.tap` = `transform: translateY(3px) scale(.98)` on `:active`, transition .08s。

### 2. Write（てがき / なぞり書き）
- **Purpose**: お手本をなぞって1文字ずつ書く。
- **Layout**: 上に戻るボタン(円 56px 白, 影 `0 3px 0 rgba(0,0,0,.08)`) + 中央ラベル「『◯◯』を なぞろう」(Zen Maru 900, 20px, `--sub`)。
  - 進捗ボックス: 文字数分の `64px` 角丸16pxマス(`--card`/border `--cbd`)、確定済み文字を 38px で表示。
  - キャンバス: `max-width:380px`, `aspect-ratio:1`, bg白, `border-radius:24px`, 影 `0 4px 16px rgba(0,0,0,.07)`。背景に薄いお手本文字(`#efe7d8`, `clamp(120px,42vw,260px)`)。前面に `<canvas>`。
  - 下に「↩ もどす」「けす」(各 flex:1, 60px, 角丸18px, 白)。
  - 確定ボタン: `min-height:80px`, 角丸22px, bg `--accent2`, 26px/900。ラベルは状態で「なぞれたよ！」→（最後の手前）「さいごの もじ！」→（完了時）「できた！」。
- **Canvas 仕様**: pointer イベントで描画。`lineWidth:20`, `lineCap/Join:round`, `strokeStyle:#2a241d`。DPRに合わせて内部解像度をリサイズ。背景は**透明**のまま（ストロークのみ）。

### 3. Reveal（のったよ / 図鑑登録演出）
- **Purpose**: 言葉が図鑑に載った祝福画面。
- **Layout**: 中央。タイトル(`--accent`, 30px/900、はっけん時は「はっけん！ ⭐」/通常「ずかんに のったよ！🎉」) → 絵文字カード(`200px`角丸36px, `--card`/border `--cbd`, 絵文字120px, `pop` アニメ) → 言葉(46px/900) → カテゴリチップ(bg `--accent2`, 白, 99px) → 説明文(22px, line-height1.8, `#5a5145`, `white-space:pre-line`)。
- **Actions**: 「つぎも かく！」(`--accent`) / 「ずかんを みる」(`--accent2`)。

### 4. Zukan（ずかん / 図鑑）
- **Purpose**: コレクション閲覧。
- **Layout**: ヘッダ(戻る / 「ずかん N けん」26px、Nは`--accent` / 右: 登録済みはチケット数 `🎟️ N`、ゲストは空)。
  - ゲスト時: 点線枠の登録促し CTA(border `--accent` dashed)。
  - 登録時: グラデの「あたらしい ことばを はっけん！」CTA(border `--accentd`)。
  - カテゴリごと: アイコン+名前(20px/900)+進捗(`got/total`)、その下に `grid` (`repeat(auto-fill,minmax(96px,1fr))`, gap12px) のセル。
    - 取得済みセル: 白カード, border `--cbd` 3px, 角丸20px, 絵文字36px+ラベル14px、タップで Detail。
    - 未取得セル: bg `--locked`, 角丸20px, 中央に `?`(#c4b6a0)。
  - 「⭐ はっけん」セクション: discovered があれば表示（セル border `#f3dd9a`）。

### 5. Detail（しょうさい）
- Reveal と同等の単体表示。絵文字カード220px, 言葉52px, カテゴリチップ, 説明文, 「YYYY/M/D に かいたよ」。

### 6. Story Pick（おはなし・ことばえらび）★MVP追加
- **Purpose**: 絵本に使う言葉を選ぶ。
- **Layout**: ヘッダ(戻る/「おはなしを つくる」22px/中央)。サブ「つかう ことばを えらんでね / 2〜5こ ・ むりょうで なんかいでも」。
  - 選択グリッド: `repeat(auto-fill,minmax(96px,1fr))`, gap12px。各エントリ=白カード, 角丸20px, `aspect-ratio:1`, border 3px。
    - 未選択 border `--cbd`、選択時 border `--accent3` + 右上に `✓` 丸バッジ(26px, bg `--accent3`)。
    - 中身: 絵文字34px + 言葉14px/900。手書き画像があれば「✍️ てがき」ラベル(10px, `--accent2`)。
  - 下部固定の生成ボタン(`min-height:80px`, 角丸22px, 「📖 おはなしを つくる（N/5）」)。選択2件未満は無効色(bg #d8cfc0 / 影 #bfb6a6)、2件以上で `--accent3`。
- **ルール**: 最大5件選択。デフォルトで先頭3件を選択済み。**チケット不要・無料で何回でも**（はっけん上限とは独立）。

### 7. Story（おはなし / 絵本ビュー）★MVP追加 — 中核
- **Purpose**: AI生成の絵本を1ページずつめくって読む。**3ページ程度**、各ページに挿絵。
- **生成中（loading）状態**: 中央に `✏️`(72px, `bob` アニメ無限) +「AIが おはなしを かいているよ」(22px/900) + 3点パルス(`dotpulse`, `--accent3`, 0/.2/.4s ディレイ) +「えらんだ ことばを つかっているよ…」。プロトタイプは ~1.6s タイマー、本番は API 待ち。
- **読書（ready）状態**: 縦フレックス。
  - **絵本ページカード**: `flex:1`, bg `#fffdf7`, border `--cbd`, `border-radius:28px`, 影 `0 6px 20px rgba(0,0,0,.08)`。カード全体タップで次ページへ。
    - **挿絵パネル（上）**: `min-height:240px`, padding `30px 20px`, 背景はページ別パステル `tints = ['#fbe7d8','#e3f0e6','#e9ebfa']`（ページidx % 3）。中央にヒーロー挿絵: 絵文字 `104px`（1語）/`78px`（2語）, `drop-shadow(0 5px 9px rgba(0,0,0,.14))`, 下に半透明白ピルの語ラベル(15px/900)。
    - **本文（下）**: `flex:1`, padding `24px 24px 20px`, `flex-wrap` で折り返し、`align-items:flex-end`。テキストは24px/500/line-height1.5/`#3a332a`。文中のモノの名前トークンは下記「手書き差し替え」。
  - **ページめくりコントロール**: 左 `‹` / 右 `›` 丸ボタン(54px白, 影, `--accent3`文字)。中央にドット(`height:10px`、現在は `width:26px` `--accent3`、他は `width:10px` `#e2d6c6`、`transition .2s`)。先頭で `‹` を `opacity:.3`、末尾で `›` を `opacity:.3`。
  - **最終ページのみ**下に「🔄 もういちど」(白/`--accent3`) と「できた！」(`--accent3`) を表示。
  - **ページ切替アニメ**: ページ内側に `fade .28s ease`（opacity0→1）を JS で付与し、完了後にインラインの `animation` を**クリア**（残すと再レンダ時に opacity0 で固着するため必須）。

#### 手書き文字 差し替え（重要仕様）
本文中のモノの名前を、子どもが Write 画面で実際に書いた**手書き文字画像（1文字=1 PNG）**にインライン差し替えする。
- 手書きがある語: 各文字画像を横並び(`height:34px`/`width:34px`/`object-fit:contain`)、白地・border `--cbd` 2px・角丸8px の小箱に収める。
- 手書きが無い語（例: はっけんで取得した語、過去データ）: フォールバックで**色付きテキスト**表示（Zen Maru 900, 26px, `--accent`, 下線3px `--accent`）。
- 手書き画像は Write の各文字確定時に `canvas.toDataURL('image/png')`（透過PNG）で取得し、`handwriting[word] = [dataURL, ...]` として語ごとに保存。`undo` で末尾を破棄、語完成時に確定保存。

### Bottom Sheets（共通モーダル）
下からスライドイン(`sheetUp .28s`)、背景 `rgba(20,15,10,.45)`、角丸 `28px 28px 0 0`、上部にグラバー(44×5px #e6ddcf)。背景タップで閉じる。
- **Signup**: ゲストが図鑑保存を促されるシート。メール/Google/Apple。登録で `authed=true` + チケット5枚付与。`collected` 3/5/10/それ以上 のタイミングで初回1回だけ自動表示。
- **Tickets**: 5枚¥320 / 15枚¥800(おすすめ) / 40枚¥1,800。Stripe 決済（保護者ゲートの先）。買い切り消費型。
- **Parent Gate**: 保護者確認。ボタンを**1.2秒長押し**で通過（進捗バー `0→100%` を表示）。離すとリセット。

## Interactions & Behavior
- **遷移**: `screen` ステートで Home / Write / Reveal / Zukan / Detail / Parent / StoryPick / Story を切替。`sheet` ステートで signup / tickets / gate を切替。
- **なぞり書き**: 1文字確定で進捗ボックスが埋まり、キャンバスをクリア。最後の文字確定で Reveal へ。
- **おはなし生成**: StoryPick→生成ボタン→Story(loading)→（タイマー/API後）ready。「もういちど」で同じ選択のまま再生成（毎回ランダムにページ構成・文面が変わる）。
- **ページめくり**: ページカードタップ or `›` で次、`‹` で前。両端でクランプ（ループしない）。
- **保護者ゲート**: 長押し1.2秒。`pointerdown`で計測開始、`pointerup/leave`でキャンセル。
- **アニメーション**: `pop`(.4s カード出現), `rise`(.4s 上方向フェード), `sheetUp`(.28s), `fade`(.2〜.28s), `bob`(1s 無限 ペン揺れ), `dotpulse`(1.2s 無限 ロード点)。永続表示要素に opacity0始点アニメを残さないこと。

## State Management
単一コンポーネントの state（本番では適切に分割推奨）:
- `screen`: 現在画面。`sheet`: 開いているシート(null可)。
- `word` / `charIndex` / `confirmed[]`: 現在なぞり中の語と進捗。
- `collected[]`: 取得済みの語。`discovered[]`: はっけんで取得した語。
- `handwriting{ word: [pngDataURL,...] }`: 語ごとの手書き文字画像。
- `authed`: 登録済みか。`tickets`: 残チケット。
- `storySel[]`: おはなしで選択中の語（最大5）。`story`: 生成済みページ配列 `[{hero:[word], tokens:[{t:'text',s}|{t:'word',w}]}]`。`storyLoading`。`storyPage`: 表示中ページidx。
- `sfx` / `bgm`: 設定トグル。
- `theme`: 配色プリセット 'A'(既定)/'B'/'C'（CSS変数で適用、下記）。

## Backend / 実装要件（プロトタイプでは模擬）
- **辞書（無料・無制限）**: 既知のひらがな語 → 絵文字・カテゴリ・やさしい説明文・イラスト。プロトタイプは `PRESETS` / `CATS` にハードコード。本番はサーバ辞書 + イラストCDN。
- **イラスト取得**: 挿絵・図鑑絵は **R2（オブジェクトストレージ）から取得**。プロトタイプの絵文字はそのプレースホルダ。
- **おはなし生成**: 登録エントリから最大5件を選び **gpt-4o-mini** に「これらの言葉を使った3〜5文の短いおはなし」を生成させる。出力を**3ページ程度**に分割し、各ページにヒーロー挿絵を割当て、文中のモノ名トークンを手書き画像/テキストに差し替えてレンダリング。**無料ユーザーも利用可（はっけん上限とは独立）**。
- **はっけん**: 辞書に無い語を AI で図鑑化。**チケット1枚消費・登録ユーザー限定**。
- **課金**: チケットは Stripe 買い切り消費型。登録・支払いは保護者ゲートの先。**子どもの個人情報は収集しない**方針。
