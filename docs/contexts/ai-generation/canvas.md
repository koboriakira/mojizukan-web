# Bounded Context Canvas: AI生成

| 項目 | 内容 |
|------|------|
| **分類** | 支援ドメイン |
| **目的** | ことばからイラスト・説明文を生成し、共有キャッシュを管理する |
| **戦略的重要性** | 中。API の差し替え（OpenAI → 他プロバイダ）やプロンプト調整は自律的に可能 |

## ユビキタス言語（主要）

イラスト、説明文、スタイル、共有キャッシュ、生成

→ 詳細は [glossary.md](../../glossary.md)

## メッセージ

### 受信（Inbound）

| メッセージ | 送信元 | 内容 |
|-----------|--------|------|
| 生成リクエスト（はっけん） | ことばあつめ | word + style → イラスト + 説明文を返す |
| 生成リクエスト（おはなし） | おはなし | words → 絵本テキストを返す |
| キャッシュ候補リクエスト | ことばあつめ | ランダムなキャッシュ済みことばを返す |

### 送信（Outbound）

| メッセージ | 送信先 | 内容 |
|-----------|--------|------|
| 生成結果 | ことばあつめ / おはなし | description + image_url / story pages |

## 主要ルート

| エンドポイント | 役割 |
|---------------|------|
| `POST /api/hakken/generate` | イラスト + 説明文生成（ことばあつめから呼ばれる） |
| `POST /api/story/stream` | おはなしテキスト生成（SSE ストリーミング） |

## 依存する外部

| サービス | 統合パターン | 用途 |
|---------|------------|------|
| OpenAI API（gpt-4o-mini） | ACL | テキスト生成（説明文・おはなし） |
| OpenAI API（gpt-image-1-mini） | ACL | イラスト生成 |
| Cloudflare R2 | ACL | 生成画像の保存・配信 |

## 共有キャッシュの設計

共有キャッシュはこのコンテキスト内のインフラ層。ドメインロジックではない。

- `shared_cache` テーブル（D1）に word × style の生成結果を保持
- キャッシュヒット → 生成スキップ（高速）
- キャッシュミス → OpenAI API で生成 → キャッシュに保存
- はっけんの可否には影響しない（[ADR-0001](../../adr/0001-domain-model-and-bounded-contexts.md) 参照）

## 変更時の注意

- API 差し替え・プロンプト調整は ADR の設計意図を守れば自律的に進めてよい
- 画像サイズの変更は Issue #117 で管理
- 新しい外部 API を初めて呼ぶ前に公式リファレンスで仕様を確認する
