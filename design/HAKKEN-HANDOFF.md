## 1. これは何か / 背景

「はっけん」は、**辞書（プリセット）に無い言葉を AI で図鑑化**する機能です。本体の図鑑は無料・無制限ですが、辞書外の言葉だけはチケットを消費して生成します（登録ユーザー限定）。

### 設計の中心転換（重要）
初期案の「親が毎回 2〜3 文字を仕込んで子に渡す」反復は**親の負担が高い**。そこで MVP は次のモデルに再設計しました。

> **親がまとめて言葉を仕込む（🎲ランダム候補も可）→ 子が『ひみつのことば』を次々となぞって"はっけん"していく** バッチ型ループ。

### モード（保護者が子の発達段階で選ぶ）
1 機能を年齢で育てる設計。保護者メニューで選択。

| モード | 主導 | 目安 | MVP |
|---|---|---|---|
| **おまかせ** | 親が言葉を全部決める。子はならんだ「?」をなぞって発見 | 3歳ごろ〜 | ✅ 本MVPで実装 |
| いっしょに | 親の仕込み＋子の自由入力の両方 | 4歳ごろ | 近日 |
| じぶんで | 子が 50音で言葉を決めてなぞる（主体的） | 5歳ごろ〜 | 近日 |

- **デフォルト = おまかせ**（確定）。
- 「いっしょに／じぶんで」は本MVPでは UI 上に表示するが非活性（「近日」）。将来、自由入力（旧・案B）を上級トグルとして解放する想定。

## 2. チケット経済（確定ルール）

- **辞書（プリセット）の言葉 = 無料・無制限**。
- **プリセットに無い言葉を図鑑化する時だけ 🎟️1枚**。
- **消費の確定タイミング = 「生成成功時」**（確定）。
  - おまかせモードでは、保護者が「はっけん準備」で言葉を仕込む際に**バッチ数ぶんのチケットがあるか確認**（不足時は購入導線）。実際の減算は、**子がその言葉を書き終えて図鑑化に成功した瞬間**に 1 枚。
  - 失敗・重複・不適切では**減らさない**。
- **子どもは課金 UI に一切触れない**（誤連打消費のガード）。購入・確認はすべて保護者メニュー（保護者ゲートの先）。
- ゲスト（未登録）は、はっけん準備に入ろうとすると**登録シート**を表示。登録で `authed=true` + チケット 5 枚付与（本体仕様）。

## 3. 画面 / Views（追加・変更分）

### 3.1 保護者メニュー ▸「はっけん準備」カード（追加）
保護者メニュー内に新カードを追加（`学習の記録` と `はっけんチケット` の間）。
- ヘッダ：見出し「はっけん準備」＋右に現在モードのピル（`モード：おまかせ`、bg `#fbeaf1` / 文字 `#9c4d70`）。
- 説明文（13px / `#6b6256`）：仕込みの目的と「消費は生成成功時」を明記。
- 仕込み中サマリ：白行に `⭐ 仕込み中の ひみつのことば` ＋ 件数（`--accent3`, 900, 18px）。
- 主 CTA「**＋ ことばを 仕込む**」：`min-height:52px`, 角丸14px, bg `--accent3 (#c2698f)`, 白900/15px → `prep` 画面へ（未登録なら `signup` シート）。
- モード選択（3枠 flex）：`おまかせ` のみ活性（border `--accent3`, bg `#fbeaf1`, 「✓」）。他 2 枠は `opacity:.6` + 「近日」。

### 3.2 はっけん準備（`prep` 画面・新規）
保護者が、子に発見させる言葉をまとめて選ぶ。**保護者ゲートの先＝親メニュー経由でのみ到達**。
- ヘッダ：戻る（→ 親メニュー）／中央タイトル「はっけん準備」（`--accent3`, 22px/900）／右にチケット数 `🎟️ N`。
- サブ説明：「お子さまが なぞって はっけんする ことばを えらんでね」＋「プリセットに ない ことば ＝ 🎟️1まい（消費は 生成成功時）」。
- **入力行**：`<input>`（`min-height:54px`, 角丸16px, border `--cbd`, 18px）＋「＋」ボタン（54px角, bg `--accent3`, 26px/900）。入力語を候補に追加。
- **🎲 ランダム候補を 3つ だす**：白地・破線 `--accent3`。`HAKKEN_WORDS`（辞書外プール）から未使用語をランダムに 3 件、**選択済み**で追加。
- **候補グリッド**（`repeat(auto-fill,minmax(150px,1fr))`, gap10）：各候補カード
  - 絵文字（既知のはっけん語はその絵文字／辞書外の自由入力は `✨`）＋語（16px/900）。
  - **判定バッジ**（後述の `classify`）。色は判定で変わる。
  - 左上「✓」（選択中・`ok` のみ）、右上「✕」（候補から除外）。タップでカード選択トグル（`ok` のみ選択可）。
- **仕込みボタン**：`⭐ N こ 仕込む`（`min-height:78px`, 角丸22px）。`N = 選択中の ok 件数`。`N>0 かつ チケット十分` で `--accent3`、不足/0 で無効色（`#d8cfc0` / 影 `#bfb6a6`）。押下で確認シート（チケット不足時は `tickets` シート）。
- 脚注：「仕込んだ言葉は ずかんに『?』で ならびます」。

#### 候補の判定 `classify(word)`
| 判定 | 条件 | バッジ文言 | 選択可 | 仕込み |
|---|---|---|---|---|
| `ok` | 既知のはっけん語 or 未知の新語 | はっけんOK（`#9c4d70`/`#fbeaf1`） | ○ | ○ |
| `dup` | 既に `collected` にある | もう ずかんに あるよ（`#c95835`/`#fff0e6`） | × | × |
| `seeded` | 既に仕込み済み | もう しこみずみ（`#8a6d1e`/`#fdf3d6`） | × | × |
| `dict` | プリセット辞書語（cat≠はっけん） | じしょに あり・むりょう（`#3f7a52`/`#e6f1e9`） | × | ×（本体の通常収集で取れる） |
| `ng` | NG リスト該当 | この ことばは つかえないよ（`#b03a3a`/`#fbe6e6`） | × | × |

### 3.3 ずかん ▸「ひみつのことば」セクション（変更）
旧「あたらしい ことばを はっけん！」CTA（子が直接起動）を**廃止**し、おまかせモデルに置換。
- `seeded.length > 0` のとき：見出し `⭐ ひみつの ことば N こ` ＋ 補足「? を かいて はっけんしよう！」（`#9c4d70`）。
  - グリッド（本体図鑑と同じ `minmax(96px,1fr)`）に「**?マス**」を `seeded` 件数ぶん表示：白地・**破線** border `#e3b8cd`・角丸20px、中央「?」（38px, `#c2698f`, 900）＋小さく「かいて みよう」。タップで `prep` ではなく**なぞり書き（発見モード）**へ（`openSecret(word)`）。
- `seeded.length === 0` のとき：保護者へ誘導する CTA（グラデ `#fbeaf1→#f7dfe9`, border `--accent3`）→ 親メニュー（ゲート）。
- 既出の「⭐ はっけん」コレクション（`discovered`）はそのまま下部に表示。

### 3.4 なぞり書き（発見モード）
本体の Write 画面を流用。`openSecret(w)` で `word=w, discovering:true` をセットして遷移。お手本・進捗・キャンバス・手書きキャプチャは**本体と同一**。最後の文字を確定すると、通常の Reveal ではなく **`hakkengen`（生成演出）** へ。

### 3.5 はっけん生成演出（`hakkengen` 画面・新規）★中核体験
辞書外語を AI 生成している「待ち」を、ワクワクする専用演出にする。
- 中央：`✨⭐✨`（30px）→ **🔮**（96px, 角丸44px, 放射 `#fff3d6→#fbeaf1` 背景, `bob` 無限アニメ）→「あたらしい ことばを つくっているよ」（24px/900）→ 3点パルス（`dotpulse`, `--accent3`, 0/.2/.4s）→「AIが えと せつめいを かいているよ…」。
- プロトタイプは **~2.2s タイマー**で `finishHakken()`。本番は生成 API の完了で遷移。
- 完了時に：`reveal` へ（`lastHakken:true`）、`discovered` と `collected` に語を追加、`seeded` から除去、**`tickets -1`（=生成成功時の消費確定）**。

### 3.6 のったよ（Reveal）／詳細（Detail）
本体と同一。`lastHakken` のときタイトルは「はっけん！ ⭐」。図鑑詳細・学習記録では `discovered` 該当語に「はっけん」バッジ。

### 3.7 ボトムシート：仕込み確認（`prepconfirm`・新規）
保護者が「必ず確認」してから仕込む（共通シートUI＝下からスライド）。
- `⭐🎟️` → 「**N こ 仕込む？**」→ 選んだ語一覧＋「チケットは…図鑑にできた時（生成成功時）に 1 枚ずつ／いま 🎟️N」。
- ボタン：「⭐ 仕込む」（`confirmSeed`）／「やめる」。脚注に「仕込み・支払いは保護者メニューの中だけ。お子さまは課金画面に触れません」。

## 4. State（本体への追加分）

```
mode: 'omakase'           // 'omakase' | 'issho' | 'jibun'（MVPは omakase のみ活性）
seeded: string[]          // 親が仕込んだ「ひみつのことば」。発見で除去
discovering: boolean      // なぞり書きが発見モードか（trueなら完了で hakkengen へ）
prepInput: string         // はっけん準備の入力欄
prepSel: { w:string, status:'ok'|'dup'|'seeded'|'dict'|'ng', selected:boolean }[]  // 候補
// screen に 'prep' / 'hakkengen' を追加。sheet に 'prepconfirm' を追加。
```

主な遷移・関数（プロトタイプ `class Component` 参照）：
- `goPrep()` … 親→prep（未登録なら signup）
- `addPrepWord()` / `rollRandom()` / `togglePrepSel()` / `removePrepSel()` … 候補編集
- `classify(w)` … 判定（§3.2）
- `openSeedConfirm()` → `confirmSeed()` … `seeded` へ確定追加（**ここでは減算しない**）
- `openSecret(w)` … 発見モードで Write へ
- `confirmChar()`（改修）… 発見モード時は完了で `hakkengen` へ
- `finishHakken()` … 生成成功＝`tickets-1`・`discovered`/`collected` 追加・`seeded` 除去・Reveal

## 5. エッジケース & 安全（幼児向けのため最重要）

| ケース | 扱い | チケット |
|---|---|---|
| 不適切・実在しない語 | サーバ辞書＋AI判定で**仕込み/検出時に弾く**。子の画面では「この ことばは まだ つくれないみたい」とやさしく。プロトタイプは `NG` リスト＋`classify` で再現 | 消費しない |
| AI が生成できない | プレースホルダ図鑑で**保留→後で生成**／リトライ。消費は生成成功時なので未消費のまま | 消費しない |
| 重複（既に図鑑にある） | 仕込み/検出時に弾き「もう ずかんに あるよ！」既存詳細へ誘導 | 消費しない |
| 通信エラー・タイムアウト | 生成は**非同期**。失敗時は「あとで できるよ」で保留し**チケット保護**、復帰で再開。子を待たせない | 保護 |

## 6. Backend / 実装要件

- **はっけん生成**：辞書外語を AI（例 gpt-4o-mini 等）で図鑑エントリ化＝`{ 絵文字/イラスト, カテゴリ='はっけん', やさしい説明文（2行・ですます「〜よ」調） }`。**イラストは R2 から取得**（プロトタイプの絵文字はプレースホルダ）。
- **入力の安全フィルタ**：不適切語・実在しない語・固有名詞等をサーバ側で判定して拒否。子向け表現でやさしくフィードバック。
- **重複検査**：仕込み時 & 生成前に `collected`/`seeded` と突合。
- **チケット**：Stripe 買い切り消費型。**減算は生成成功のトランザクションでのみ確定**（失敗時ロールバック）。仕込み時は残数チェックのみ。
- **🎲ランダム候補**：辞書外の「はっけん向き」語プールから、未収集・未仕込みを除いて N 件サンプリング。ソース設計（カテゴリ別／年齢別／季節）は §8 で要相談。
- **永続化**：`seeded` / `discovered` / `handwriting` はアカウントに紐付け（複数セッションをまたいで子が消化）。子の個人情報は収集しない方針を維持。
