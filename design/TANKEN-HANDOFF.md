## 1. これは何か / 背景

`HAKKEN-HANDOFF` の「モード」設計（おまかせ／いっしょに／じぶんで）のうち、**じぶんで**を実装。子どもが **50音で自分で言葉を組み立て → なぞって → 図鑑化**する、子ども主導のループです。

### 命名の確定（重要）
保護者が選ぶ「モード」ではなく、**ホームに2つの遊びを常設**する形に変更。子どもが毎回その場で選べます。

| ホームのボタン | 旧称 | 主導 | 中身 |
|---|---|---|---|
| 🔍 **みつける** | おまかせ | 親 | 親が用意した「ひみつのことば」＋未収集の辞書語を、さがして なぞる |
| 🧭 **たんけんに でる** | じぶんで | 子 | 子が 50音で 言葉を作り、なぞって 図鑑化（辞書外は はっけん） |

- 「いっしょに」モードは廃止（みつける＋たんけんの併存で実質カバー）。
- 旧ホームの「✏️ もじを かく」（次の辞書語を自動提示）は **みつける** に内包（みつける画面の「🎲 おまかせで 1つ えらぶ」として存続）。

### 入力方式の決定 ＝ **方式A（50音表・全表示）**
`Jibun-Mode-Explorations.dc.html` で 3案を実機比較した結論。

| 案 | 内容 | 判定 |
|---|---|---|
| **A：50音表（全部見える）** | あ〜ん を一覧。直接タップ | ✅ **採用**。一覧性が高く、幼児の「探す」に最適 |
| B：行→段の2ステップ | 行を選ぶ→5つの段から | 候補。大きく迷わないが2タップ。年少向け代替として将来検討 |
| C：フリック風（タップ十字） | 行を押すと周りに段がポップ | 不採用。コンパクトだが「行→段」の概念が幼児には難しい |

> 補助記号（**濁点 ゛／半濁点 ゜／小文字 小／長音 ー**）の共通ツールバーは方式によらず常設。

## 2. 画面 / Views（追加・変更分）

### 2.1 ホーム（変更）
中央寄せの縦並び。
- **🔍 みつける**（`--accent2` 緑, 90px, 2段組: 見出し＋「おまかせ ・ よういされた ことばを さがそう」）→ `mitsukeru`。
- **🧭 たんけんに でる**（`--accent` 橙, 90px, 2段組: 「じぶんで ・ すきな ことばを つくって はっけん」, **NEWバッジ**）→ `tanken`。
- 下段 flex：**📖 ずかん**（白）／**📚 おはなし**（`--accent3`, `storyAvailable` 時のみ）。
- **🏠 おうちの ひとは こちら**（テキストボタン）→ 保護者ゲート。

### 2.2 みつける（`mitsukeru`・新規）
親が用意した候補を「さがして かく」ハブ。
- ヘッダ：戻る／中央「🔍 みつける」（`--accent2`）。サブ「よういされた ことばを さがして かこう」。
- **⭐ ひみつの ことば**（`seeded.length>0`）：破線 `#e3b8cd` の「?マス」を仕込み数ぶん。タップ＝発見なぞり（`openSecret`）。
- **✏️ かいて あつめよう**（未収集の辞書語があるとき）：絵文字＋語のカード。タップ＝通常なぞり（無料収集 `goWriteWord(w,false,'normal')`）。
- 空状態（辞書語を全収集 かつ 仕込み0）：やさしい完了メッセージ＋たんけん誘導。
- 最下部：**🎲 おまかせで 1つ えらぶ**（白＋緑枠）→ `goWrite`（次の辞書語を自動）。

### 2.3 たんけん（`tanken`・新規）★中核
方式A の言葉づくり画面。
- ヘッダ：戻る／中央「🧭 たんけん」（`--accent`）／右に **きょうの はっけん**の pips（`dailyHakkenMax` 個・消費で `--accent3` 点灯）。
- **スロット**：組んだ文字（最大6）を `#fff8ee` の枠で表示＋末尾に空マス。右に「ぜんぶ けす」。
- **補助ツールバー**（共通）：`⌫ もどす` ／ `゛` ／ `゜` ／ `小` ／ `ー`。直前の文字を濁点等に変換（`tkConvert`）。
- **50音表**：`ROWS`（あ行〜わ行、5列）を `aspect-ratio:1` の白キーで。空欄（や行・わ行の穴）は不可視スペーサ。
- **判定メッセージ**（`tankenMsg`）：重複・NG時に橙バナー。
- CTA **✏️ これを かく（N もじ）**：1文字以上で活性。押下＝`tkNext()`（後述の分岐）。

### 2.4 たんけん おしまい（`tankenlimit`・新規）
じゆうはっけん枠が 0 のときに 辞書外語を作った場合の、**やさしい停止画面**。
- 🌙（bob）＋「きょうの たんけんは おしまい！」＋「『◯◯』は あした はっけん できるよ。いまは みつける で あそぼう！」＋「※ かいすうは おうちの方が きめています」。
- ボタン：**🔍 みつける へ**（`goMitsukeru`）／**🏠 ホーム**（`goHome`）。**課金・親ゲートは一切出さない**。

### 2.5 なぞり書き（Write）／のったよ（Reveal）／詳細（Detail）（流用・小改修）
本体 Write をそのまま使用。`goWriteWord(word, discovering, kind)` で語・モードを設定して遷移。
- **Reveal タイトル**は `revealKind` で出し分け：
  - はっけン完了（`lastHakken`）かつ `kind==='tanken'` → 「**あたらしい ことば はっけん！⭐**」
  - はっけン完了かつ `kind==='mitsuke'`（みつける/ひみつのことば）→ 「**みつけた！⭐**」
  - 通常（辞書語の無料収集）→ 「**ずかんに のったよ！🎉**」
- **辞書外の新語フォールバック**：`PRESETS` に無い語は `HAKKEN_EMOJI`（例 おに=👹）→ 無ければ `⭐/✨`。説明文は「あたらしい ことばを みつけたよ。ずかんに のったよ。」、カテゴリは「はっけん」。Detail・図鑑セルも同様にフォールバック。

### 2.6 保護者メニュー ▸「みつける と たんけん の じゅんび」カード（変更）
旧「はっけん準備」カードを統合・改称。
- 見出し改称、右ピル「保護者が設定」。
- 説明：**みつける**＝ひみつのことば仕込み（🎲ランダム可）／**たんけん**＝1日回数を設定。チケット消費は**生成成功時**。
- 既存の「⭐ みつける用 ひみつのことば（件数）」＋「＋ ことばを 仕込む」（→ `prep`）は維持。
- **新規：🧭 たんけん の 1日かいすう**（`−` / `dailyHakkenMax` / `＋`、0〜9）。注記「辞書外を図鑑化＝🎟️1まい（生成成功時）／辞書語は無料／遊び中に課金画面は出ない」。

## 3. たんけんの分岐ロジック `tkNext()`

組んだ語 `w` を `classifyTanken(w)` で判定して分岐。

| 判定 | 条件 | 挙動 | チケット / 枠 |
|---|---|---|---|
| `ng` | NGリスト該当 / 空 | `tankenMsg`「この ことばは まだ つくれないみたい」（画面維持） | 消費なし |
| `dup` | 既に `collected` | `tankenMsg`「『◯◯』は もう ずかんに あるよ！」 | 消費なし |
| `dict` | 辞書語（`PRESETS` かつ `cat≠はっけん`） | Write（`discovering:false`）→ Reveal「のったよ」 | **無料** |
| `hakken` | 上記以外の有効語（辞書外） | 枠・チケットが残れば Write（`discovering:true`）→ `hakkengen` → `finishHakken`。**不足なら `tankenlimit`** | 成功時に 🎟️ −1 ＋ 枠 −1 |

- **枠/チケットのゲートは「これを かく」押下時**（`dailyHakkenUsed>=dailyHakkenMax` または `tickets<=0` で `tankenlimit`）。
- **実消費は生成成功時**（`finishHakken`）：`tickets-1`、`tankenMode` のとき `dailyHakkenUsed+1`。失敗・中断では減らさない（本体ルール踏襲）。

### じゆうはっけん枠（★案Bの摩擦を解消する核）
案Bの弱点＝「遊びの最中に親ゲートが頻繁に挟まる」。本実装は **保護者が事前に1日回数を許可**し、枠が続く限り**子はノンストップ**、0で `tankenlimit` にやさしく着地。**遊び中に親ゲート/課金UIは一切出ない**。枠＝チケットの安全キャップ（子が一気に使い切らない）。

## 4. State（本体への追加分）

```
tankenChars: string[]      // たんけんで組み立て中の文字（最大6）
tankenMsg: {type:'dup'|'ng', w?} | null
dailyHakkenMax: number     // 親が決める1日のじゆうはっけん回数（既定3, 0〜9）
dailyHakkenUsed: number    // 当日の消費数（pips表示・0で停止）
tankenMode: boolean         // 今のWriteがたんけん由来か（finishHakkenで枠を減らす判定）
revealKind: 'normal'|'mitsuke'|'tanken'  // Revealタイトルの出し分け
limitWord: string           // tankenlimitに出す語
// screen に 'mitsukeru' / 'tanken' / 'tankenlimit' を追加
```

データ：`ROWS`（50音）/ `DAKU` / `HANDAKU` / `SMALL`（補助記号変換表）/ `HAKKEN_EMOJI`（辞書外の既知語→絵文字フォールバック）を getter で追加。

## 5. 主要関数

- `goMitsukeru()` / `goTanken()` … ホーム→各画面。
- `goWriteWord(w, discovering, kind)` … 語・モードを指定して Write へ（みつける候補・たんけん共通の入口）。
- `tkAdd/tkBack/tkClear` … 文字編集。`tkConvert(map)` → `tkDaku/tkHandaku/tkSmall/tkChouon`。
- `classifyTanken(w)` … §3 の判定。
- `tkNext()` … §3 の分岐。
- `finishHakken()`（改修）… 生成成功＝`tickets-1`、`tankenMode` なら `dailyHakkenUsed+1`。
- `incDaily()/decDaily()` … 保護者の1日回数設定（0〜9）。
- `openSecret(w)`（小改修）… `revealKind:'mitsuke'` を付与。

## 6. エッジケース & 安全（幼児向けのため最重要）

| ケース | 扱い | チケット |
|---|---|---|
| 不適切・実在しない語 | サーバ辞書＋AI判定で弾く。子には「この ことばは まだ つくれないみたい」。プロトは `NG`＋`classifyTanken` で再現 | 消費しない |
| 重複（既に図鑑） | 「もう ずかんに あるよ！」（プロトは `tankenMsg`／本番は既存詳細へ誘導推奨） | 消費しない |
| 1日の枠を使い切り | `tankenlimit` でやさしく停止。**親ゲートは出さない**。翌日リセット（本番要実装） | 消費しない |
| チケット不足 | 枠が残っていても `tankenlimit`（または保護者導線）で停止。子に課金UIは見せない | 消費しない |
| AI生成失敗・通信断 | 非同期・保留→リトライ。消費は生成成功時のため未消費のまま（本体ルール） | 保護 |

## 7. Backend / 実装要件（たんけん固有・追補）

- **1日回数（枠）の永続化とリセット**：`dailyHakkenMax`（保護者設定）と `dailyHakkenUsed`（当日消費）をアカウントに紐付け。**日付境界（端末TZ／サーバ基準は要決定）でリセット**。
- **入力安全フィルタ**：子の自由入力のため、`HAKKEN-HANDOFF §6` の不適切・実在しない・固有名詞判定をサーバ側で厳格に。子向け表現でやさしく拒否。
- **辞書照合の所在**：`classifyTanken` のローカル辞書はプロトのみ。本番は**サーバ辞書（プリセット）＋重複（collected/seeded）照合**で `dict/dup/ng/hakken` を確定。
- **生成**：辞書外語を AI で図鑑エントリ化（絵文字/イラスト＝R2、カテゴリ=はっけん、やさしい説明文）。`HAKKEN_EMOJI` はプロトのフォールバックで、本番は生成結果で置換。
- **チケット**：減算は**生成成功トランザクションでのみ確定**。枠とチケットの二重ゲート（枠＝子の安全キャップ、チケット＝親の通貨）。

## 8. デザイントークン / 命名

- ホーム：みつける＝`--accent2`（緑・収集）、たんけん＝`--accent`（橙・冒険＋NEW）。

- 50音キー：白地＋`--cbd` 枠、文字 `--ink`、`Zen Maru Gothic` 900。補助記号は薄ボタン。
- メッセージ（重複/NG）：`#fff0e6`／枠 `#f0c4ad`／文字 `#c95835`。
- フォント・余白・角丸・タッチターゲット（44px以上）・既存キーフレーム（`bob/pop/fade/dotpulse`）は本体準拠。テーマA/B/Cにも追従（var フォールバック）。
