## 1. brief からの変更点

brief の前提（簡素化方針そのもの）に対する**変更は なし**。brief で「実装済み」とされていた簡素化は、プロトタイプ（dc.html）が v1 段階のままだったため、本セッションで dc.html に反映した。あわせて、議論で以下を確定した。

- **ずかんの並び順を「新しい順（最新が先頭）」に確定**。登録順の単純な昇順ではなく逆順で表示し、最近とった語が埋もれないようにする。
- **保護者メニューの学習記録を「習得数のみ」から最小限拡張**。「今週 N個」と「最近の ことば（直近5語）」の2点だけを追加（カテゴリ別進捗は廃止のまま）。
- **STARTER_WORDS（共有キャッシュの種＝みつける初期プール）を10語に確定**：いぬ・ねこ・くま・うま・とり・やま・はな・つき・さかな・すいか。全て清音・2〜3文字・絵にしやすい・かな行を散らした構成。半濁音「ぱん」は初手のなぞり難度が高いため除外。
- **STARTER_WORDS の位置づけを明文化**：恒久的な固定プールではなく「共有キャッシュが空の初期状態の種データ」。共有キャッシュが育てば、みつけるの候補はキャッシュから動的に選ばれる。
- **無限スクロール／仮想化は不採用**。収集語は数十〜100規模で、過剰実装。グリッドが下に伸びるだけで十分。

## 2. ユーザータイプ別フロー

### A. 未ログイン（ゲスト）
1. ホーム（たんけん／おはなしに 🔒）
2. みつける（ゲスト可）→ 出題1語を自動抽選（prepared→STARTER_WORDS）
3. なぞり書き → はっけん中（キャッシュヒットで速い／ミスで遅い）
4. のったよ（絵・名前・説明）→ ずかん（フラットグリッド・新しい順・点線の登録促し）
5. たんけん／おはなしを押す → 登録シート → 認証後に目的機能へ自動遷移

### B. ログイン済み（みつける）
1. ホーム → みつける → 出題抽選：**未収集の prepared が1つでもあれば必ず prepared から**、無ければ未収集の STARTER_WORDS（共有キャッシュの種）
2. なぞり書き → はっけん中 → のったよ
3. 「つぎも かく」でループ／「ずかんを みる」へ
4. prepared も STARTER も尽きたら → 復習モード（既得語を再なぞり＝再発見）または「ぜんぶ みつけた」画面（保護者へ相談）

### C. ログイン済み（たんけん）
1. ホーム → たんけん（50音で言葉を作る）
2. `classifyTanken` 判定
   - NG → エラーで差し戻し
   - ずかんに既存 → **再発見**としてなぞり書きへ（チケット不要・Reveal は「また あえたね！😊」）
   - それ以外（新規） → なぞり書きへ。チケット消費は生成時のキャッシュ判定に委ねる
3. 残高0 かつ キャッシュミス（AI生成が必要）→ 「チケットが なくなったよ」画面 → みつける／ホームへ回遊
   - ※ 日次回数制限は廃止（ADR-0002）。制御軸はチケット残高のみ

### D. 再発見（同じことばで再生成・rediscovery）
1. しょうさい（登録済みの語）→「🎨 べつの えに する」→ 再生成 確認シート（チケット不要）
2. はっけん中（再生成演出）→ しょうさい（新しい絵で更新・件数は増えない）
3. 失敗時 → 元の絵を保持

### E. おはなし接続
1. ずかん／ホーム → おはなしホーム → ことばえらび（2〜5語）→ 🎟️1枚 → 執筆中（約1分）→ 完成 → よむ
2. ショートカット：のったよ／しょうさい →「📚 この ことばで おはなし」→ 当該語を選択済みで ことばえらびへ

### F. 保護者（準備）
1. 保護者ゲート（長押し）→ おうちの方メニュー
2. 学習の記録（習得数・今週・最近のことば）を確認
3. 『みつける』ことばの準備 →「＋ ことばを 登録する」→ 入力 or 🎲ランダム候補 → 登録（チケットは生成成功時に消費・キャッシュにある語は無料）

## 4. 却下した案と理由

- **ずかん子ども画面にソート／検索を置く**：3〜6歳には不要で操作の負荷が高い。検索が要るなら保護者ゲートの先に置く。
- **ずかんに無限スクロール／仮想化**：収集語は数十〜100規模で、実装コストに見合わない。グリッドが伸びるだけで十分。
- **STARTER_WORDS に半濁音「ぱん」を残す**：初手のなぞりに半濁点が必要で難度が高い。最初の10語は全て清音に寄せる。
- **学習記録を「習得数のみ」に固定**：数字単体は動機づけに弱い。data slop を避けつつ「今週」＋「最近のことば」の2点だけ最小限で追加。
- **固定10語を恒久の出題プールにする**：prepared を使い切った全ユーザーが同じ10語に収束し「みんな同じ」感が出る。共有キャッシュ前提の「種データ」に留め、キャッシュが育てば動的抽選にする。
- **たんけんの重複を確認付きで通す**：毎回の確認が遊びのテンポを損なう。再発見はチケット不要なので無確認でそのまま通す（ADR-0002）。
- **「ひみつのことば」「仕込む」表現の維持**：子どもに語の出自を意識させる／意味深な響きがあるため、UI からは排除し「準備ことば／登録する」に統一（子ども画面では出自表示そのものを撤廃）。
