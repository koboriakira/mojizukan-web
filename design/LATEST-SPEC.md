# Handoff: もじずかん (Mojizukan) — 幼児向け 手書き文字あつめ & はっけん & おはなし生成

> このREADMEは**現行プロトタイプ `Mojizukan-Hakken-Prototype.dc.html` の確定仕様**を単独で実装できるよう自己完結でまとめたものです。
> 旧 `Mojizukan-Prototype.dc.html` 用の記述（および `HAKKEN-HANDOFF.md` / `MITSUKERU-HANDOFF.md` / `TANKEN-HANDOFF.md`）はこの版に統合・更新されています。差異がある場合は**本READMEと `Mojizukan-Hakken-Prototype.dc.html` を正**としてください。

## Overview
もじずかん は、子どもが画面に文字を「なぞって書く」ことでひらがなの言葉を集め、図鑑（ずかん）として育てる幼児向けWebアプリです（対象 約3〜6歳・モバイル縦画面）。

子どもの2つの遊び方 + 保護者の準備:
1. **みつける（おまかせ発見）** — 用意された言葉を1つ出題。子どもは*何の言葉かを伏せられたまま*なぞり、書き終えると正体（絵・名前・説明）が判明。
2. **たんけん（じぶんで作る）** — 50音キーボードで子ども自身が言葉を作り、なぞって発見。1日の回数を保護者が設定。
3. **ずかん** — 集めた言葉をカテゴリ別コレクションとして閲覧。未発見は「？」。
4. **おはなし** — 集めた言葉から短い絵本を生成。本文中のモノ名を、子どもが実際に書いた手書き文字画像に差し替え表示（無料・回数無制限）。
5. **おうちの方メニュー（保護者ゲートの先）** — 今日の準備（みつける用の言葉仕込み・たんけん回数）、学習記録、チケット購入(Stripe)、設定。

## About the Design Files
このバンドルの **`Mojizukan-Hakken-Prototype.dc.html` が唯一の最新デザインリファレンス**（全画面・全ロジックを含む）です。HTMLで作られた**プロトタイプ**であり、そのまま本番に貼るコードではありません。

タスクは、これらのデザインを**ターゲット環境（React / Vue / SwiftUI / ネイティブ等）の既存パターン・ライブラリで再現する**こと。環境が無ければ最適なフレームワークを選定（タッチ中心・Canvas必須なので React + Canvas かネイティブが有力）。`.dc.html` / `support.js` は社内プロトタイピング用ランタイムで、**移植不要**。ロジックは HTML 内 `<script>` の `class Component`（状態遷移・なぞりエンジン・手書きキャプチャ・ストーリー生成）を参照。

## Fidelity
**High-fidelity (hifi)**。色・タイポ・余白・角丸・影・アニメーション・なぞりフィードバックの挙動は確定値。下記トークン／実装メモに従いピクセル単位・挙動単位で再現してください。データソースのみ未接続（プロトタイプはローカル辞書とタイマーでAIを模擬）。

## Layout / 全体
- モバイル縦画面前提。中央寄せ、`max-width: 560px`、左右 `padding: 0 20px`、下 `padding-bottom: 28px`。
- 本文フォント **Zen Kaku Gothic New**、見出しフォント **Zen Maru Gothic**（いずれも Google Fonts、500/700/900）。
- 単一コンポーネント内の `screen` ステートで画面を切替（SPA）。モーダルは下からスライドインするボトムシート（`sheet` ステート）。
- 全タップ要素に `.tap` クラス相当の押下感: `:active` で `translateY(3px) scale(.98)`、transition .08s。

### 子ども画面 と 保護者画面 のトーン使い分け（重要）
- **子ども画面**（ホーム/みつける/たんけん/てがき/のったよ/ずかん/しょうさい/おはなし）: **ひらがな主体**・分かち書き・絵文字・まる文字見出し。
- **保護者画面**（おうちの方メニュー/はっけん準備/各確認シート）: **通常の日本語表記（漢字・通常の文章）**。専門用語は平易に。
- 「みつける」「たんけん」は機能名として保護者画面でもそのまま使用。

### 2. Write（てがき / なぞり書き）— 中核体験

- **はげまし文**（キャンバス下, 14.5px/700, `min-height:20px`）: 未描画「ゆびで なぞってね ✏️」(`#b6ab9a`) → 描画後「いいね！かけたら ボタンを おしてね」(`#3f8e63`)。
- **確定ボタン**（`min-height:80px`, 角丸22px, 26px/900, transition .2s）:

  - **描画あり**: bg `--accent2` / 影 `--accent2d`、ラベル「**なぞれたよ！**」（最後の1文字では「**できた！**」）。
- **進行**: 文字確定で進捗ボックスが埋まりキャンバスをリセット、次の文字へ。最後の文字確定で:
  - 通常/たんけん辞書語 → **Reveal**。
  - 発見モード（みつける secret / たんけんで新語） → **HakkenGen（生成演出）** を経て Reveal。

#### 手書き文字 差し替え（重要仕様）
本文中のモノ名を、子どもが Write で実際に書いた**手書き文字画像（1文字=1 PNG）**にインライン差し替え。
- 手書きあり: 各文字画像を横並び(`height/width:34px`, `object-fit:contain`)、白地・border `--cbd` 2px・角丸8px の小箱に収める。
- 手書きなし（はっけん取得語・過去データ等）: フォールバックで色付きテキスト（Zen Maru 900, 26px, `--accent`, 下線3px）。
- 取得元: Write の各文字確定時に**インク用オフスクリーンCanvas**を `toDataURL('image/png')`（透過PNG）化し `handwriting[word]=[dataURL,...]`。`undo` で末尾破棄、語完成時に確定保存。

### 11. おうちの方メニュー（Parent、保護者ゲートの先）
※情報設計: **最重要アクション（今日の準備）を最上部**に、説明は平易・簡潔に。
- **ヘッダ**「おうちの方メニュー」+ **受け渡しブリッジバナー**（グラデ `#fff3d6→#fbeaf1`, border `#ecd58f`）: 🤝「お子さまから交代しましたね / 学習のようすを確認したり、次に遊ぶ言葉を準備できます。」（子ども→保護者のトーン接続）。
- **① 今日の準備カード**（最重要）: 見出し「🎯 今日の準備」+「保護者が設定」ピル。本文「お子さまが遊ぶ言葉をここで準備します。遊び方は2種類あります。」
  - **🔍 みつける（保護者が言葉を選ぶ）**サブカード（白）: 「選んだ言葉が図鑑に『？』で並びます。お子さまがなぞると発見できます。」+「準備済みの言葉 N個」(ピンク帯) + ボタン「**＋ 言葉を準備する**」(`--accent3`) → **はっけん準備** 画面へ。
  - **🧭 たんけん（お子さまが作る）**サブカード（白）: 「お子さまが自分で言葉を作って発見します。1日に遊べる回数を設定できます（0でお休み）。」+ カウンター `− / 1日 N回 / ＋`（0〜9, `--accent3`）。
  - 脚注「※ 辞書にない言葉を図鑑にすると🎟️を1枚使います（生成成功時のみ）。辞書にある言葉は無料です。遊びの最中に課金画面は表示されません。」
- **② 学習の記録カード**: 「N 個の文字・ことばを記録」+ 称号(`milestone()`) + 進捗バー(`--accent2`) + 記録リスト（絵文字+語+カテゴリ+はっけんバッジ、**`max-height:188px` でスクロール**）。空時はプレースホルダ。
- **③ はっけんチケットカード**: `🎟️ N 枚` + 説明 + 「チケットを追加（Stripe）」(`--accent`) + 「購入を復元」。
- **④ 設定カード**: トグル行 **「読み上げ（文字を音声で）/ まだ字が読めないお子さま向け」** → **「効果音」** → **「BGM」**（各 52×30px スイッチ、ON時 `--accent2`）。「お子さまの生年月」「イラストのスタイル」（表示のみ）。
- **⑤ リンクカード**: お問い合わせ / プライバシーポリシー / 利用規約。フッタ「もじずかん Web ・ プロトタイプ」。

### 12. はっけん準備（Prep、保護者画面）
みつける用の「ひみつの ことば」を仕込む。
- ヘッダ: 戻る / 「はっけん準備」(`--accent3`) / `🎟️ N`。
- サブ「お子さまがなぞって発見する言葉を選びます / プリセットにない言葉＝🎟️1枚（消費は生成成功時）」。
- **入力**: テキスト入力（placeholder「ひらがなで入力」）+「＋」。/「🎲 ランダム候補を3つ出す」（未使用のはっけん語からランダム）。
- **判定 `classify(w)`** → カードのステータスバッジ:
  | status | バッジ文言 | 選択可 |
  |---|---|---|
  | `ok` | 発見OK | ✓（既定で選択） |
  | `dup` | すでに図鑑にあります | × |
  | `seeded` | 仕込み済み | × |
  | `dict` | 辞書にあり・無料 | × |
  | `ng` | この言葉は使えません | × |
  - カード: 白/border、絵文字+語、`✕`で削除、`✓`で選択トグル（ok のみ）。
- **CTA**「⭐ N個を仕込む」（ok選択数, `prepCount()`）。チケット不足なら Tickets シート。押下で **PrepConfirm シート**。
- 仕込んだ語は `seeded[]` に追加され、ずかんに「？」で並ぶ。

## なぞりフィードバック 実装メモ（最重要・新規）
「塗りつぶし達成率」ではなく、**なぞる行為そのものを気持ちよくする**方針。塗り率ゲートは廃止。

### Canvas 構成（Write画面）
表示用 `<canvas>` 1枚 + **オフスクリーン2枚**（インク用 `ink`、お手本マスク用 `mask`）を同サイズで保持。粒子配列 `parts[]`。
1. **お手本マスク `mask`**: 対象1文字を `Zen Maru Gothic 900`、`fontSize ≈ canvasH*0.66`、中央に黒で塗り描画（`buildMask`）。文字が変わるたび再生成。フォント未ロード時のズレ防止に `document.fonts.ready` 後へ再ビルドフック。
2. **インク `ink`**: ポインタ操作で線を描く。`lineWidth ≈ max(15, H*0.08)`, `round`, `strokeStyle = --accent`（テーマ追従）。**描画はこのオフスクリーンに蓄積**（表示Canvasには都度合成）。
3. **表示合成 `renderTrace()`**（毎フレーム）: クリア → お手本 `mask` を `globalAlpha 0.14` で薄く描画（=なぞる対象のガイド）→ `ink` を等倍描画 → 粒子を描画。
4. **キラキラ粒子 `spark(x,y,n)`**: ポインタ down / 一定距離ごとの move で数個生成。色は `['#ffd24a','#ff9e5e','#7ad0a0','#f0a6c4','#ffffff']` からランダム。各粒子 `{vx,vy,life,decay,size,rot,col}`、重力 `vy+=0.05`、`vx*=0.98`、`life-=decay` で消滅。4点星形（`starPath`）で描画、`globalAlpha=life`。上限200個。
5. **アニメループ `startLoop()`**: `requestAnimationFrame` で `renderTrace` を回し、**描画中 or 粒子が残る間だけ**継続（idleで停止しCPU節約）。Canvas が消えたら停止。
6. **チャイム音 `twinkle()`**: Web Audio。`AudioContext` を初回ポインタで遅延生成（gesture後）。ペンタトニック `[523.25,587.33,659.25,783.99,880,1046.5]` からランダムな1音を `sine` で短く（gain 0→0.1→0、~0.22s エンベロープ）。最短85ms間隔にスロットル。**効果音設定 `sfx` OFF で無音**。
7. **完了ゲート**: 「描いたか」だけ。最初のストロークで `drew=true`。確定ボタンは `drew` で有効化。`confirmChar()` 冒頭で `if(!drew) return`。`けす`/`もどす`で `drew=false`・粒子クリア・`ink` クリア。
8. **手書きキャプチャ**: `ink.toDataURL('image/png')`（=子どもの実際のストロークのみ、お手本/粒子は含めない）。

### 音声読み上げ（任意・読めない子向け）
- `speechSynthesis`（`SpeechSynthesisUtterance`, `lang='ja-JP'`, `rate .85`, `pitch 1.2`）。設定 `speak` で ON/OFF（既定 ON）。
- 発話タイミング: たんけんのキー押下（その1文字）/ Write の🔊（今なぞる1文字）/ Reveal・Detail の表示時自動＆🔊（語全体）。
- 端末/ブラウザの日本語音声に依存（非対応環境では無音・try/catchで握りつぶし）。

## Interactions & Behavior
- **遷移**: `screen` = home / write / reveal / mitsukeru / tanken / tankenlimit / hakkengen / zukan / detail / parent / prep / storypick / story。`sheet` = prepconfirm / signup / tickets / gate。
- **みつける**: `mitsukePool()`（seeded をシャッフル先頭 + 未取得プリセット）から1語。seeded なら発見モードWriteへ、プリセットも発見モード。プール空なら復習モード or mitsukeru画面。
- **たんけん**: 50音で語を組み立て→`classifyTanken`→辞書語は無料Write、新語はチケット&日次上限を消費して発見。
- **はっけん（新語の図鑑化）**: Write 完了 → HakkenGen → Reveal。`tickets-1`、たんけん経由なら `dailyHakkenUsed+1`。
- **アニメーション**: `pop`(.4s), `rise`(.4s), `sheetUp`(.28s), `fade`(.2〜.28s), `bob`(無限 揺れ), `dotpulse`(1.2s 無限)。永続表示要素に opacity0 始点アニメを残さない。

## State Management
単一コンポーネント state（本番は適切に分割推奨）:
- `screen` / `sheet`。
- `word` / `charIndex` / `confirmed[]` / `drew`（現在語・進捗・描画有無）。
- `revealKind`: 'normal'|'mitsuke'|'tanken'|'review'（ラベル・遷移先・伏字を分岐）。`tankenMode`。
- `collected[]` / `discovered[]` / `seeded[]`（取得語・発見語・仕込み語）。
- `handwriting{ word:[pngDataURL,...] }`。
- `tankenChars[]` / `tankenMsg`（たんけん作成中・エラー）。
- `dailyHakkenMax` / `dailyHakkenUsed` / `limitWord`（日次上限）。
- `authed` / `tickets`。
- `storySel[]` / `story` / `storyLoading` / `storyPage`。
- `sfx` / `bgm` / `speak`（設定トグル）。
- `prepInput` / `prepSel[{w,status,selected}]`（はっけん準備）。
- `theme`: 配色プリセット 'A'(既定)/'B'/'C'（CSS変数で適用）。
- ※ なぞりエンジンの `ink`/`mask`/`parts`/`AudioContext`/`requestAnimationFrame` はインスタンス変数（React外の命令的リソース）として保持。

## Backend / 実装要件（プロトタイプでは模擬）
- **辞書（無料・無制限）**: 既知ひらがな語 → 絵文字・カテゴリ・やさしい説明文・イラスト。プロトタイプは `PRESETS` / `CATS` にハードコード。本番はサーバ辞書 + イラストCDN。
- **イラスト**: 図鑑絵・絵本挿絵は **R2（オブジェクトストレージ）から取得**。絵文字はプレースホルダ。
- **はっけん（新語の図鑑化）**: 辞書にない語を AI（例 gpt-4o-mini）で絵・説明生成。**チケット1枚消費・登録ユーザー限定**。みつける（保護者仕込み）/ たんけん（子ども作成）の両方が入口。
- **おはなし生成**: 登録語から最大5件で短い絵本（3〜5文）を生成→3ページ程度に分割→ヒーロー挿絵割当 + モノ名トークンを手書き画像/テキストに差し替え。**無料・回数無制限**。
- **課金**: チケットは Stripe 買い切り消費型。登録・支払いは保護者ゲートの先。**子どもの個人情報は収集しない**。
- **NGワード**: `NG` 配列でフィルタ（本番はサーバ側 + 拡張辞書）。
