# もじずかん Web版 — 引き継ぎサマリー

別のデザインエージェント／開発者への引き継ぎ用まとめ。**2026.06.28 時点**。

---

## 0. 一言で

既存 iOS アプリ「もじずかん」（ひらがなを手書きで集める 4〜6歳向け学習アプリ）を、**スマホ・タブレット両対応の Web アプリ**として作り直すプロジェクト。本フェーズでは **要件・MVP定義 → ビジュアル方向性 → コア画面プロトタイプ** までを作成。

元仕様は `uploads/SPEC.md`（iOS版の全機能仕様）を参照。

## 2. 確定した意思決定

1. **Web化の狙い**：生成AI×子供向け iOS は審査が通りにくい → Web で回避。Web の方が配布・販売が容易。人気が出ればネイティブも再検討。
2. **手書き（MVP）**：PencilKit/ML Kit は使えない。**A1 = なぞり書き中心＋簡易完了判定（文字認識なし）**。お手本をなぞって「なぞれたよ！」で確定。自由手書き＋クラウド認識（A2）は後フェーズ。
3. **AIはっけん**：サーバー前提なので **共有キャッシュ＋バッチ生成**（SPEC #45）が自然。単語文字列のみ送信、PIIなし。
4. **課金＝チケット制（決定）**：**プリセット辞書の登録は無料・無制限**／**AIはっけん（辞書外の単語）1回＝チケット1枚消費**。サブスクではなく消費型。Stripe でパック購入（5/15/40枚）。
5. **ビジュアル**：**A「やさしい図鑑」をデフォルト**。後からテーマ変更できる設計（プロトタイプは theme プロップ A/B/C で切替実装済み）。
6. **デバイス**：スマホ・タブレット同等に重視（レスポンシブ）。
7. **オンボーディング/認証ファネル**：
   - ① ログイン不要でゲスト即体験（最初の1文字は「いぬ」。後で簡単な2文字に差し替え可）
   - ② **3件・5件・10件・以降1件ごと**に登録を提案（ゲスト図鑑を引き継ぎ＋無料チケット5枚付与）
   - ③ チケットを使い切ったら Stripe で購入
   - 匿名ファースト／パスワードレス推奨／保護者ゲートの先で登録・購入／子どものPIIは集めない。

## 3. MVP スコープ（フェーズ）

- **MVP-1（書いて集まる）**：コア体験（なぞり→登録）／プリセット辞書／図鑑 一覧・詳細／レスポンシブ／保護者ゲート・効果音
- **MVP-2（売る・記録する）**：保護者ページ（設定・学習の記録）／チケット課金（Stripe）／AIはっけん（キャッシュ型）／マイルストーン・称号
- **あとで**：アルバム/シェアカード／自由手書き＋認識（A2）／イラストスタイル選択・BGM／学習モード・利用時間管理

詳細・優先度の根拠は `要件定義・MVP.dc.html` の各セクション参照。

---

## 4. ビジュアルシステム

- **デフォルト = A「やさしい図鑑」**：背景クリーム `#fdf6ec` ／ カード `#fff8ee`（枠 `#f0e4d0`）／ 文字 `#2a241d` ／ アクセント コーラル `#e8714c`（押下影 `#c95835`）／ サブアクセント ミント `#5fb583`（影 `#3f9b68`）／ ロック `#f3ece0`。
- **フォント**：見出し = Zen Maru Gothic（丸ゴシック）／ 本文 = Zen Kaku Gothic New。
- **テーマ切替**：プロトタイプは CSS カスタムプロパティ（`--bg` `--card` `--accent` `--fhead` 等）＋ `var(..., A既定値)` のフォールバックで実装。`themes` マップに B（フィールドノート）/ C（ポップ＆クリア）を定義済み。theme プロップで切替。
- 図鑑の絵は**現状すべて絵文字プレースホルダー**。本番はイラスト（プリセット画像／AI生成）に差し替え前提。

### 子ども（4〜5歳）向けの設計原則
- タップ領域 最小 72px、主要ボタンはさらに大きく
- 学習対象のひらがな・絵は大きく表示、説明文 22px
- 1画面の要素を絞る／余白広め／高コントラスト
- 読めない前提でアイコン＋音に寄せ、文字は補助

## 5. プロトタイプの実装メモ（次の担当者向け）

- 起動時は**ゲスト状態で手書き画面**から開始（初めて触る人起点）。
- 画面ルーティングは `state.screen`（home / write / reveal / zukan / detail）＋ `state.sheet`（signup / tickets）を `<sc-if>` で出し分け。
- 手書きキャンバスは `<canvas>` にポインタイベントで描画（`setupCanvas`）。**認識はしていない**（A1方式）。お手本文字は背面に薄く表示。
- 出題は `WORDPOOL` を簡単な順に。プリセット定義は `PRESETS`、カテゴリは `CATS`、はっけん候補は `HAKKENPOOL`。
- 登録提案タイミングは `goZukan()` 内の `c===3||c===5||c===10||c>10`（`_lastPromptCount` で同件数の再表示を抑止）。
- 認証・購入は**モック**（`doSignup`＝即 authed＋5枚付与、`buy(n)`＝即加算）。実装時は実際の認証基盤・Stripe に差し替え。
