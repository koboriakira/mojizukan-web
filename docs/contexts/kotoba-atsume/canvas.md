# Bounded Context Canvas: ことばあつめ

| 項目 | 内容 |
|------|------|
| **分類** | コアドメイン |
| **目的** | 子どもがことばを集めてずかんを作る体験を提供する |
| **戦略的重要性** | 高。アプリの中心体験。みつける/たんけん/はっけんのフロー、チケット消費判定がここに集中する |

## ユビキタス言語（主要）

ことば、ずかん、みつける、たんけん、はっけん、なぞる、再発見、仕込みことば

→ 詳細は [glossary.md](../../glossary.md)

## メッセージ

### 受信（Inbound）

| メッセージ | 送信元 | 内容 |
|-----------|--------|------|
| canSpend 結果 | アカウント・経済 | チケット残高が足りるか |
| 生成結果 | AI生成 | 説明文 + イラスト URL |
| 共有キャッシュ候補 | AI生成 | みつける候補としてのキャッシュ済みことば |

### 送信（Outbound）

| メッセージ | 送信先 | 内容 |
|-----------|--------|------|
| 語一覧 | おはなし | ずかんに登録済みのことば一覧（zukanWords） |
| 生成リクエスト | AI生成 | word + style |
| spendTicket | アカウント・経済 | はっけん時にチケット1枚消費 |

## 主要ルート

| エンドポイント | 役割 |
|---------------|------|
| `POST /api/hakken/generate` | はっけん生成（キャッシュ確認 → AI生成 → ずかん登録） |
| `GET /api/hakken/cache` | 共有キャッシュからみつける候補を取得 |

## 依存する外部

なし（永続化は D1、画像は R2 経由だがインフラ層の関心事）

## 変更時の注意

- 不変条件の変更は人間レビュー必須
- チケット消費ロジックの変更は売上に直結するため人間判断
- みつける/たんけん/はっけんのフロー変更はE2Eテストで検証する
