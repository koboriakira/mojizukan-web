# ユビキタス言語グロッサリー

もじずかんで使う用語の定義。コード・ドキュメント・会話すべてでこの用語を使う。

> 出典: [ADR-0001](adr/0001-domain-model-and-bounded-contexts.md)

## 名詞

| 用語 | 定義 | コード上の名前 |
|------|------|---------------|
| ことば | ずかんに入れる対象。ひらがなのみ or カタカナのみの文字列（混在不可） | `word` |
| ずかん | ユーザーが集めたことばの一覧 | `zukan` / `zukanWords` |
| 説明文 | ことばの意味を説明する短いテキスト。ことばと1:1 | `description` |
| イラスト | ことば × スタイルに対する画像。ことばとN:1 | `illustration` / `image_url` |
| スタイル | イラストの画風（ehon, pop, watercolor, zukan, honwaka） | `style` / `ImageStyle` |
| 共有キャッシュ | ことば×スタイルの生成結果をユーザー横断で保持するインフラ層の仕組み | `sharedCache` / `shared_cache` |
| 準備ことば | みつけるで提示される候補を保護者が事前に登録した語。未登録なら共有キャッシュからランダムに候補を出す | `prepared` |
| チケット | 生成に消費するリソース | `ticket` |
| 残高 | 現在のチケット数 | `balance` |
| おはなし | ずかんの語を素材にAIが生成する絵本 | `story` |

## 動詞

| 用語 | 定義 | 前提条件 | 結果 |
|------|------|---------|------|
| みつける | 候補リストからことばを選ぶ。保護者が登録した語があればそれを優先、なければキャッシュからランダム提示 | なし | なぞる画面へ遷移 |
| たんけん | 子どもが50音表からことばを自分で組み立てる | なし | なぞる画面へ遷移 |
| なぞる | 文字の輪郭をキャンバス上でなぞって書く | 対象のことばが決まっている | 全文字なぞり完了でconfirm |
| はっけん | ずかんに未登録のことばをずかんに登録する | なぞり完了 + ずかんに未登録 | AI生成（または共有キャッシュ）→ ずかんに追加 |
| 再発見 | 既にずかんにあることばを再度見つける | なぞり完了 + ずかんに登録済み | チケット消費なし |
| 付与 | チケットを増やす（サインアップボーナス等） | なし | 残高が増える |
| 消費 | チケットを使う（はっけん・おはなし生成時） | `canSpend(balance)` が true | 残高が1減る |

## 状態遷移（ことばあつめ）

```
[ホーム]
  ├─ みつける → [なぞる] → 全文字完了
  │                         ├─ ずかんに未登録 → [はっけん中] → [ずかんに登録済み]
  │                         └─ ずかんに登録済み → [再発見]
  └─ たんけん → [ことば組み立て] → [なぞる] → (同上)
```

## コンテキスト依存の用語

| 用語 | ことばあつめ | おはなし | AI生成 |
|------|------------|---------|--------|
| ことば | ずかんに登録する対象 | 物語の素材として選ぶ対象 | 生成リクエストのキー |
| 生成 | はっけん時のイラスト・説明文生成 | 絵本テキストの生成 | APIへのリクエスト処理 |
| チケット | はっけんに1枚消費 | おはなし生成に消費（枚数は未定） | （使わない） |

## 使わない用語

| 使わない | 代わりに使う | 理由 |
|---------|------------|------|
| プリセット | 共有キャッシュ | プリセット語の概念は廃止。キャッシュの有無はインフラ関心事 |
| カード / アイテム | ことば / エントリ | ドメイン用語を統一する |
| 絵文字 | イラスト | emoji フィールドは廃止済み（ADR-0001） |
| AI エントリ / 動的エントリ | はっけんしたことば | 出自による区別はドメインレベルでは不要 |
| 日次回数制限 / `daily_hakken_max` | チケット残高 | 制御軸をチケットに統一（ADR-0002） |
| `HAKKEN_WORDS` / 静的プリセット語リスト | 準備ことば + 共有キャッシュ | 動的プール化（ADR-0002） |
| 重複ブロック / `dup` | 再発見 (`rediscovery`) | ずかんにある語の再入力は再発見として許容（ADR-0002） |
| ひみつのことば | 準備ことば | 子ども向け表示名として使っていたが、子どもに区別を意識させる必要がないため廃止 |
| 仕込みことば / 仕込む | 準備ことば / 登録する | 「仕込む」は意味深な表現のため、平易な「登録する」に統一 |
| カテゴリ分類 | （なし） | ずかんは収集語を登録順に表示する。カテゴリ分類は将来再検討 |
