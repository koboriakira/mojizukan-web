# ディレクトリ構造の進化タイミング

現在の構造を維持し、以下のシグナルが出たら対応するリファクタリングを行う。

| シグナル | アクション |
|---------|-----------|
| API ルートが10本超 | `src/index.ts` を薄い export + `src/app.ts`（Hono 本体）に分離 |
| D1 のクエリ・スキーマが増えた | `src/db/` を新設し schema.ts + クエリ関数を集約 |
| `src/lib/` が5ファイル超 | `src/services/` にリネームし、ドメイン単位でサブディレクトリ化を検討 |
| クライアント JS の画面が増えた | `src/client/` 内を screens/ と shared/ に分割 |
| E2E テストが5本超 | テストファイルをフロー単位で分割（`e2e/auth.spec.ts` 等） |

根拠: [[Wiki/技術/CF_Workers_Hono_Vanilla_JS_SPA_ディレクトリ構造パターン]] の「小さく始めてシグナルが出たら分割する」原則。
