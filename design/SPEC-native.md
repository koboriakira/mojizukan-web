# もじずかん 仕様書

## 1. プロダクト概要

| 項目 | 内容 |
|------|------|
| プロダクト名 | もじずかん |
| コンセプト | ひらがなを手書きすると、イラストと説明文つきで図鑑に登録されていく子ども向け学習アプリ |
| プラットフォーム | iOS / iPadOS |
| 対象年齢 | 4〜6歳（App Store 表記: 4+） |
| 価格モデル | 無料（App内課金: プレミアム 500円 買い切り） |
| カテゴリ | Education / Kids（Age 5 & Under） |

### コア体験ループ

```
文字を書く → 認識される → 言葉が完成 → イラストと説明文が表示 → 図鑑に登録 → もっと書きたくなる
```

## 4. 画面仕様

### 4.1 タイトル画面

- 背景色: クリーム（`AppTheme.background`）
- アイコン: 📖✏️（64pt）
- タイトル: 「もじずかん」（52pt、丸ゴシック太字）
- ボタン（縦並び）:
  - 「はじめる」: コーラル（`AppTheme.buttonStart`）
  - 「ずかん」: グリーン（`AppTheme.buttonZukan`）
  - 「おやのページ」: テキストのみ（18pt）
- BGM: 画面表示時に再生開始

### 4.2 手書き入力画面

iPhone と iPad でレイアウトが異なる。

#### 共通要素

- **ことばエリア**: 確定済み文字を角丸ボックス（56×56pt）で横並び表示
- **「1もじ もどす」ボタン**: 直前の1文字を取り消し
- **キャンバス**: PencilKit ベースの手書き領域（白背景、指＋Apple Pencil対応）
  - インク: monoline、黒、太さ20pt
  - お手本選択時: 薄いグレー（75%サイズ）でガイド文字を重畳表示
- **操作ボタン**:
  - 「よめるかな？」（青）: 文字認識を実行し確定
  - 「かんせい」（緑）: 単語入力を完了
  - 「ぜんぶけす」（赤）: 全文字を消去（確認ダイアログなし）
  - 「もどる」（グレー）: 前画面に戻る

#### iPhone レイアウト
- キャンバスは正方形
- 「おてほん えらぶ」ボタンでひらがなピッカーをシート表示

#### iPad レイアウト
- キャンバスの左右にひらがなグリッドを常時表示
  - 左: 清音
  - 右: 濁音・半濁音・その他

#### 完了後の表示パターン

| 状態 | 表示内容 |
|------|---------|
| プリセット一致 | プリセット画像 + 単語 + 説明文 +「ずかんに のったよ！」 |
| はっけん（AI生成） | AI画像 or emoji + 単語 + 説明文 +「はっけん！」 |
| バリデーション中 | ProgressView +「しらべてるよ...」 |
| 画像生成中 | ProgressView +「ずかんを つくってるよ...」 |
| バリデーション失敗 | 🤔 + 理由メッセージ |
| 登録上限到達 | 🔒 +「とうろくの じょうげんだよ」 |
| はっけん上限到達 | ⭐ +「はっけん！の むりょう ぶんを つかいきったよ」 |
| 辞書にない（API無効） | ❓ +「まだ ずかんに ないよ」 |

完了後は「つぎも かく！」と「ずかんを みる」のボタンが表示される。

### 4.3 図鑑一覧画面

- グリッド: `LazyVGrid`、カラム幅最小100pt（adaptive）
- ナビゲーションタイトル:「ずかん（N けん）」
- 称号バナー: マイルストーン達成時に黄色帯で表示（🏅アイコン付き）

#### プリセットセクション
- 1件以上登録済みのカテゴリのみ表示
- ヘッダー: カテゴリアイコン + 名前 +「X/Y」+ 👑（コンプリート時）
- 登録済み: プリセット画像 + 単語（手書き画像があればそれを表示）
- 未登録:「？」+ ドット → タップでヒントシート

#### はっけんセクション
- ⭐アイコン + AI画像 or emoji + 単語

### 4.4 図鑑詳細画面

- 画像: 200×200pt（プリセット画像 / AI生成画像 / emoji）
- 単語: 手書き画像があれば `HandwrittenWordView`、なければテキスト
- 説明文
- カテゴリバッジ（アイコン + ラベル）
- 登録日:「yyyy/M/d に かいたよ」

### 4.5 ヒント画面（シート）

- `.medium` detent のハーフシート
- emoji（80pt）
- 文字グリッド: 1文字目のみ表示、残りは「？」
- ヒント: 説明文の最初の1文（最初の「。」まで）
- 「わかった！」で閉じる

### 4.6 保護者メニュー

表記ルール: 保護者向け画面は通常の日本語表記（漢字・カタカナ含む）。

`List` 形式、4セクション構成:

| セクション | 項目 |
|-----------|------|
| 設定 | お子さまの情報 / はっけん画像のスタイル |
| 成長の記録 | 学習の記録 / アルバム |
| サポート | ご意見・ご要望（Google Forms）/ お問い合わせ（メール） |
| プレミアム（未購入時のみ） | 購入ボタン（価格表示）/ 購入を復元 |

#### 保護者チュートリアル（初回遷移時のみ）

3ステップのシート表示。全ステップスキップ可:

1. **生年月の設定**: お子さまの生年月登録 →「設定へ進む」/「あとで設定する」
2. **学習の記録の紹介**: 登録履歴の説明 →「学習の記録を見てみる」/「あとで見る」
3. **アルバムの紹介**: シェア機能の説明 →「アルバムを見てみる」/「あとで見る」

完了後 `isParentTutorialCompleted = true` をセット。

### 4.7 学習の記録（登録履歴）

- 全エントリを日付降順で `List` 表示
- 各行: 画像サムネイル（40×40pt）+ 単語 + 日付
  - 生年月設定済みの場合:「yyyy/M/d（X歳Yヶ月）」形式で表示
- はっけんエントリには「はっけん！」バッジ

### 4.8 アルバム（シェア機能）

#### エントリ選択画面
- タイトル入力欄（任意）
- エントリ一覧（チェックマーク選択式）
- 無料ユーザーのはっけんエントリ: 🔒 +「有料版で解放」
- ツールバー「プレビュー」→ プレビュー画面

#### プレビュー・共有画面
- `ShareCardView` を幅600ptで画像レンダリング
- シェアボタン → `UIActivityViewController`

#### シェアカードのレイアウト
- 幅600pt固定
- 任意のタイトルテキスト
- `LazyVGrid`（最大3列）でエントリカード表示
  - 各カード: 120×130pt、画像/emoji + 手書き単語 or テキスト
- フッター:「もじずかん」

### 4.9 イラストスタイル選択

5種類のスタイルから選択。各スタイルにサンプル画像4枚（いぬ/でんしゃ/はな/りんご）を表示。

| スタイル | 説明 |
|---------|------|
| ほんわか（デフォルト） | パステルカラー、丸みのある形 |
| えほん | 鉛筆＋水彩の手描き風 |
| ポップ | 太い黒輪郭線、ビビッドな色、カートゥーン調 |
| やさしい水彩 | 透明感のある水彩画 |
| ずかん | 正確な博物図鑑風イラスト |

## 5. データモデル

### 5.1 ZukanEntry（SwiftData @Model）

図鑑エントリの永続化モデル。

| フィールド | 型 | 説明 |
|-----------|---|------|
| `word` | `String`（.unique） | ひらがな単語（主キー） |
| `category` | `String` | カテゴリ名（WordCategory の rawValue） |
| `registeredAt` | `Date` | 登録日時 |
| `isDiscovered` | `Bool` | false=プリセット、true=はっけん（AI生成） |
| `generatedImageData` | `Data?` | AI生成画像（PNG）。プリセットは nil |
| `generatedDescription` | `String?` | AI生成説明文。プリセットは nil |
| `emoji` | `String?` | 画像がないときのフォールバック |

### 5.2 HandwrittenCharacter（SwiftData @Model）

手書き文字画像の保存。単語ごと・文字位置ごとに1レコード。

| フィールド | 型 | 説明 |
|-----------|---|------|
| `word` | `String` | 親単語 |
| `character` | `String` | 文字（1文字） |
| `position` | `Int` | 単語内の位置（0始まり） |
| `imageData` | `Data` | 手書き画像（PNG、16ptパディング付き） |
| `createdAt` | `Date` | 作成日時 |

### 5.3 WordEntry（構造体）

プリセット辞書のエントリ定義。

| フィールド | 型 | 説明 |
|-----------|---|------|
| `word` | `String` | ひらがな単語 |
| `emoji` | `String` | 代表絵文字 |
| `category` | `WordCategory` | カテゴリ |
| `description` | `String` | 子ども向け説明文（全ひらがな、1文15字以内、2文構成） |
| `imageName` | `String`（computed） | アセット画像名（= `word`） |

### 5.4 永続化

- ストレージ: SwiftData（SQLite）
- ファイル: `ApplicationSupport/default.store`（+ .shm, .wal）
- スキーマ破損時の防御: `ModelContainer` 初期化失敗時にストアファイルを削除して再作成

## 7. 手書き文字認識

### 7.1 認識エンジン

- **Google ML Kit Digital Ink Recognition**（言語: ja）
- デバイス上で完結（オフライン対応）
- 初回起動時にモデルをダウンロード（セルラー・バックグラウンド許可）

### 7.2 入力データ形式

```
InkPoint: { x: Float, y: Float, timeMillis: Int }
InkStroke: { points: [InkPoint] }
```

- タイミングは最初のストロークの作成時刻からの相対ミリ秒

### 7.3 認識フロー

1. ユーザーがキャンバスに1文字を書く
2. 「よめるかな？」をタップ
3. ストロークデータを ML Kit に送信
4. 認識結果から最初のひらがな/カタカナを抽出
5. カタカナの場合はひらがなに変換（Unicode -0x60）
6. 確定文字を「ことばエリア」に追加
7. キャンバスをクリアし、描画を PNG でキャプチャ（16ptパディング付き）

### 7.4 お手本モード

- ひらがなピッカーから文字を選択すると、キャンバスにガイド文字を薄く表示
- お手本選択中は認識処理をスキップし、選択された文字をそのまま確定

## 8. はっけん機能（AI図鑑エントリ生成）

プリセット辞書にない単語を書いた場合に、AIがイラストと説明文を生成して図鑑に追加する機能。

### 8.1 処理フロー

```
単語入力完了
  → プリセット辞書検索（一致すれば即登録）
  → 不一致 → WordValidator でバリデーション
    → 有効 → DescriptionGenerator で説明文生成
      → ImageGenerator でイラスト生成
        → 図鑑に「はっけん！」として登録
    → 無効 → 理由メッセージを表示
```

### 8.2 AIサービス構成

| サービス | モデル | 用途 |
|---------|--------|------|
| WordValidator | gpt-4o-mini | 単語の妥当性判定 |
| DescriptionGenerator | gpt-4o-mini | ひらがな説明文の生成 |
| ImageGenerator | gpt-image-1 | イラスト画像の生成 |

API: OpenAI API（`https://api.openai.com/v1`）

### 8.3 バリデーション基準

以下をすべて満たす単語のみ有効:

1. 実在する具体的な名詞であること
2. 子どもにとって安全な言葉であること（暴力・性的・恐怖を含まない）
3. 絵に描ける対象であること（抽象概念は不可）
4. 子どもが知っている、または知るべき対象であること

### 8.4 説明文生成ルール

1. すべてひらがなで記述（漢字・カタカナ不可）
2. 1文15文字以内
3. 3〜4文で構成
4. 感覚的・具体的な表現を使用
5. 楽しく魅力的な内容

レスポンス: `{ "text": "...", "category": "...", "english": "..." }`

### 8.5 画像生成

- サイズ: 1024×1024px
- 品質: low
- 出力形式: base64 JSON（フォールバック: URL ダウンロード）
- プロンプト: 選択されたイラストスタイルのテンプレートに単語の英語名を埋め込み
- 全プロンプト末尾に "White background, no text, no letters." を付加

### 8.6 アーキテクチャ移行計画（#45）

現在のリアルタイムAI生成から、共有キャッシュ＋バッチ生成方式への移行を予定:

- サーバーへの送信は単語文字列のみ（PII なし）
- キャッシュヒット → 即時発見
- キャッシュミス → バッチ待ち（時間差発見）
- 人気単語は定期的にプリセットに昇格

## 9. チュートリアル

### 9.1 子ども向けチュートリアル

初回起動時に「うし」の登録を通じて操作を学ぶ8ステップのガイド。
スポットライトオーバーレイ（半透明黒 + 楕円くり抜き）で対象を強調。

| ステップ | 画面 | ターゲット | メッセージ |
|---------|------|-----------|-----------|
| 1. tapStart | タイトル | 「はじめる」ボタン | 「ここを おしてみよう！」 |
| 2. traceU | 手書き入力 | キャンバス | 「「う」を ゆびで なぞってみよう！」 |
| 3. tapConfirmU | 手書き入力 | 「よめるかな？」 | 「ここを おしてみよう！」 |
| 4. traceShi | 手書き入力 | キャンバス | 「つぎは「し」！ なぞってみよう！」 |
| 5. tapConfirmShi | 手書き入力 | 「よめるかな？」 | 「ここを おしてみよう！」 |
| 6. tapComplete | 手書き入力 | 「かんせい」 | 「ここを おしてみよう！」 |
| 7. tapZukan | 手書き入力 | 「ずかんを みる」 | 「ずかんを みてみよう！」 |
| 8. zukanHighlight | 図鑑一覧 | うしのエントリ | 「もじを かけば かくほど ずかんが ふえていくよ！」 |

ステップ2で自動的に「う」、ステップ4で「し」のお手本ガイドをセット。

### 9.2 スポットライト実装

- `PreferenceKey`（`NamedSpotlightKey`）で対象ビューの座標を収集
- `coordinateSpace` + `GeometryReader` で座標補正
- 半透明オーバーレイ + `blendMode(.destinationOut)` で楕円くり抜き
- メッセージ配置: `.above`（上 + 下向き矢印）または `.bottomTrailing`（右下 + 左向き矢印）
