# Bounded Context Canvas: アカウント・経済

| 項目 | 内容 |
|------|------|
| **分類** | 汎用ドメイン |
| **目的** | ユーザー認証とチケット（課金リソース）の管理を提供する |
| **戦略的重要性** | 中。技術的に差別化されない汎用領域だが、チケット消費ルールは売上に直結する |

## ユビキタス言語（主要）

チケット、残高、付与（grant）、消費（spend）、canSpend、フリーミアム制限

→ 詳細は [glossary.md](../../glossary.md)

## メッセージ

### 受信（Inbound）

| メッセージ | 送信元 | 内容 |
|-----------|--------|------|
| canSpend 問い合わせ | ことばあつめ / おはなし | 残高が足りるか確認 |
| spendTicket | ことばあつめ / おはなし | チケット1枚消費 |
| grantTicket | 認証フロー | サインアップボーナス等でチケット付与 |

### 送信（Outbound）

このコンテキストは他コンテキストへ能動的にメッセージを送らない。問い合わせに応答するのみ。

## 主要ルート

| エンドポイント | 役割 |
|---------------|------|
| `POST /api/auth/signup` | 新規登録 + チケット付与 |
| `POST /api/auth/login` | ログイン |
| `POST /api/auth/logout` | ログアウト |
| `GET /api/auth/me` | セッション確認 + 残高取得 |
| `GET /api/auth/google` | Google OAuth |

## フリーミアム制限

| 条件 | 制限 |
|------|------|
| 未認証ユーザー | はっけん10体まで（クライアント側で制御） |
| 認証済みユーザー | サインアップ時にチケット50枚付与。以降はチケット消費 |
| チケット切れ | 402 応答。追加チケットの購入手段は未実装（Stripe 予定） |

## 依存する外部

| サービス | 用途 |
|---------|------|
| D1 | users / sessions / tickets テーブル |
| Google OAuth | ソーシャルログイン |
| Stripe（未実装） | チケット購入 |

## 変更時の注意

- **チケット消費ルールの変更は人間判断**（売上・利益に直結）
- フリーミアム制限の閾値（10体/50枚）変更も人間判断
- 認証フローの変更はセキュリティレビュー推奨
