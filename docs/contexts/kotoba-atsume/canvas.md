# Bounded Context Canvas: ことばあつめ

| 項目 | 内容 |
|------|------|
| **分類** | コアドメイン |
| **目的** | 子どもがことばを集めてずかんを作る体験を提供する |
| **戦略的重要性** | 高。アプリの中心体験。みつける/たんけん/はっけんのフロー、チケット消費判定がここに集中する |

## ユビキタス言語（主要）

ことば、ずかん、みつける、たんけん、はっけん、なぞる、再発見、準備ことば、おためしことば

→ 詳細は [glossary.md](../../glossary.md)

## 認証要件（ADR-0003）

| フロー | ゲスト | ログイン済み |
|--------|--------|------------|
| みつける | おためしことば（10語）のみ。キャッシュヒットで完結 | 準備ことば + 共有キャッシュ語 + おためしことば |
| たんけん | 利用不可（ログイン誘導） | 自由入力 → AI生成 |
| はっけん | おためしことばのキャッシュ結果のみ | キャッシュ or 新規生成（チケット消費） |
| 保護者メニュー | 利用不可（ログイン誘導） | 準備ことば管理 + 設定 |

## メッセージ

### 受信（Inbound）

| メッセージ | 送信元 | 内容 |
|-----------|--------|------|
| canSpend 結果 | アカウント・経済 | チケット残高が足りるか |
| 生成結果 | AI生成 | 説明文 + イラスト URL |
| 共有キャッシュ候補 | AI生成 | みつける候補としてのキャッシュ済みことば |

### 送信（Outbound）

| メッセージ | 送信先 | 内容 |
|-----------|--------|------|
| 語一覧 | おはなし | ずかんに登録済みのことば一覧（zukanWords） |
| 生成リクエスト | AI生成 | word + style |
| spendTicket | アカウント・経済 | はっけん時にチケット1枚消費 |

## 主要ルート

| エンドポイント | 役割 |
|---------------|------|
| `POST /api/hakken/generate` | はっけん生成（キャッシュ確認 → AI生成 → ずかん登録） |
| `GET /api/hakken/cache-words` | 共有キャッシュからみつける候補の語一覧を取得 |
| `POST /api/hakken/merge-guest-entries` | ゲストの `localStorage` 収集語をサインイン後にアカウントへマージ（許可リスト照合・冪等。認証必須） |

## ゲスト/アカウント間データライフサイクル（guest-account-data-lifecycle spec, Issue #225/#228）

- `localStorage` はゲスト専用ストレージ。認証中は一切書き込まない
- サインイン後の初期化は「認証確認 → マージ → クリア → サーバーから取得 → 上書き」の直列処理
- マージは ADR-0003 の「おためしことば」許可リストのみを許可し、それ以外は黙って棄却する
- ログアウトはハードリダイレクトで全クライアントステートを破棄する（ゲストに戻る）

## 依存する外部

なし（永続化は D1、画像は R2 経由だがインフラ層の関心事）

## 変更時の注意

- 不変条件の変更は人間レビュー必須
- チケット消費ロジックの変更は売上に直結するため人間判断
- みつける/たんけん/はっけんのフロー変更はE2Eテストで検証する
